# 홈 화면 설계서 (v0.1)

> 대상: 개발 에이전트(구현), QA 에이전트(검증) · 작성: 기획 · 2026-11-04

## 1. 앱 이름과 컨셉

- **앱 이름: 누니 (Nooni)** — "눈높이"에서 따온 이름. 짧고 부르기 쉬우며, 눈 모양 마스코트로 확장 가능.
- **한 줄 컨셉:** "내 눈높이에 맞춘 오늘의 공부, 친구랑 같이 레벨업!"
- 로고 표기: `누니` + 작은 눈 아이콘(●● 두 점, CSS로 그림).

## 2. 비주얼 방향

**톤:** 보드게임 카드처럼 또렷하고 손에 잡히는 느낌. 따뜻한 종이색 배경 + 진한 잉크색 글자 + 굵은 포인트 색. 흔한 보라색 그라데이션·유리효과(glassmorphism)는 쓰지 않는다. 카드는 **2px 잉크색 테두리 + 아래쪽으로 밀린 단단한 그림자**(`box-shadow: 0 4px 0 var(--ink)`)로 "누를 수 있는 게임 버튼" 느낌을 준다. 버튼을 누르면 그림자가 줄며 2px 내려간다.

**색상 토큰 (`:root`에 정의)**

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FBF6EC` | 페이지 배경(따뜻한 종이색) |
| `--surface` | `#FFFFFF` | 카드 배경 |
| `--ink` | `#1E1B2E` | 본문 글자, 테두리, 그림자 |
| `--ink-2` | `#5C586E` | 보조 글자 (흰 배경 대비 약 6.6:1) |
| `--line` | `#E9E1D2` | 구분선, 비활성 트랙 |
| `--brand` | `#FF6B35` | 주 포인트(탱저린). **채움 전용**, 위 글자는 `--ink` |
| `--brand-ink` | `#C2410C` | 탱저린 계열 글자가 필요할 때 |
| `--cobalt` | `#2B44E0` | 보조 포인트, 링크·활성 탭 (흰 글자 대비 OK) |
| `--xp` | `#FFC233` | XP 바, 코인/보상 |
| `--mint` | `#14B88A` | 완료·온라인 표시(채움) |
| `--mint-ink` | `#0B7A5B` | 완료 글자 |
| `--easy` / `--mid` / `--hard` | `#D3F5E6` / `#FFE7A8` / `#FFD3C2` | 난이도 배지 배경 (글자는 `--ink`) |

**타이포그래피**
- 본문: **Pretendard** — `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css`. 대체 글꼴: `"Noto Sans KR", system-ui, sans-serif`.
- 숫자 강조(레벨, XP, 순위)·로고: **Black Han Sans** (Google Fonts). 게임 점수판 느낌. 본문에는 쓰지 않는다.
- 크기: 화면 제목 22px/800, 섹션 제목 18px/800, 본문 15px/500, 보조 13px/500. 숫자는 `font-variant-numeric: tabular-nums`.
- 한국어 줄바꿈: `word-break: keep-all`.

**모양:** 카드 모서리 18px, 버튼 14px, 배지는 완전 둥근(pill). 간격 단위 4px(4/8/12/16/24). 좌우 여백 16px.

## 3. 레이아웃 원칙

- 기준 폭 390px. 데스크톱에서는 `max-width: 430px` 열을 가운데 정렬, 바깥은 `--bg`보다 살짝 진한 `#F1EADB`.
- 한 화면 세로 스크롤. 하단 탭바는 화면 아래 고정(열 폭과 동일), 본문 하단에 탭바 높이(72px)+안전영역 만큼 여백.
- 가로 스크롤 금지. 단, **과목 바로가기**만 가로 스와이프 리스트 허용(그 안에서만 스크롤, 페이지 자체는 가로로 밀리지 않음).

## 4. 홈 화면 구성 (위 → 아래)

1. **상단 헤더** (`#header`)
   - 왼쪽: 로고 `누니`. 오른쪽: 🔥 연속 학습 `12일` 배지, 🪙 코인 `340`, 알림 종 버튼(빨간 점 표시).
   - 인사: "안녕, **김민지**님! 오늘도 한 단계 올라가 볼까요?"
   - 레벨 카드: 큰 숫자 `Lv.7` + 칭호 `탐구하는 새싹` / XP 바 `1,240 / 1,500 XP` / 아래 작은 글씨 "다음 레벨까지 260 XP".
2. **오늘의 맞춤 학습** (`#today`) — 가장 큰 카드, 탱저린 배경.
   - 상단 라벨 "내 눈높이 추천" + 난이도 배지(`보통`).
   - 과목·제목: `경영통계` / "표본분포와 중심극한정리 감 잡기".
   - 추천 이유 한 줄: "지난 퀴즈에서 '표준오차' 정답률 58% → 기초 예제부터 다시 볼게요".
   - 정보: ⏱ 15분 · 문제 8개 · +120 XP. 진행 바 `3/8 완료`.
   - 버튼 `이어서 학습하기 ▶` (`#btn-start`). 보조 링크 "난이도 바꾸기" (`#btn-level`).
3. **오늘의 퀘스트** (`#quests`) — 제목 옆 "2/4 완료".
   - 체크 리스트 4개. 각 행: 아이콘, 제목, 보상(`+30 XP`), 오른쪽 `완료` 버튼(완료 시 ✓ 체크와 줄긋기, 버튼 비활성).
   - 4개 모두 완료하면 하단에 "🎁 보너스 상자 열기" 버튼 활성화(+100 XP, +50 코인).
4. **함께 공부하는 친구** (`#friends`)
   - 가로 아바타 줄: 친구 6명(이니셜 원형 아바타, 온라인은 민트 점). 첫 칸은 `+ 친구 초대`.
   - 아래 "지금 열린 방" 카드 2개: 방 이름, 종류 배지(`대결`/`스터디`), 참여 인원 `3/4`, 남은 시간, `참여` 버튼.
5. **이번 주 랭킹** (`#ranking`)
   - 세그먼트 토글 `우리반` / `전체` (`role="tablist"`).
   - 상위 5명 목록: 순위(1~3위는 금·은·동 원형), 이름, 학과, 주간 XP. **내 행**은 `--xp` 연한 배경으로 강조, 5위 밖이면 목록 아래 구분선 후 내 순위 표시.
   - 하단 문구: "주간 랭킹은 일요일 자정에 초기화돼요".
6. **내 과목 바로가기** (`#courses`) — 가로 스와이프 카드. 각 카드: 과목 색 띠, 과목명, 진도 %, 다음 차시.
7. **하단 탭바** (`#tabbar`, `<nav>`) — `홈` `학습` `대결` `랭킹` `내정보`. 아이콘(인라인 SVG 또는 이모지) + 글자. 활성 탭은 `--cobalt` 글자와 위쪽 3px 막대.

## 5. 인터랙션 (js/app.js)

| # | 동작 | 결과 |
|---|---|---|
| I1 | 퀘스트 `완료` 클릭 | 해당 퀘스트 완료 처리, XP 증가, XP 바가 0.6초 동안 부드럽게 늘어남, "+30 XP" 떠오르는 숫자 애니메이션, 상단 "n/4 완료" 갱신 |
| I2 | XP가 1,500 이상 | 레벨 업: `Lv.8`로 변경, 남은 XP 이월, 축하 모달 "레벨 업! Lv.8 '꾸준한 탐험가'" + 확인 버튼 |
| I3 | 퀘스트 4개 모두 완료 | 보너스 상자 버튼 활성 → 클릭 시 +100 XP, +50 코인, 버튼은 "받기 완료"로 비활성 |
| I4 | `이어서 학습하기` 클릭 | 하단 모달(바텀시트): 학습 제목, "8문제 중 4번부터 시작해요", `시작` / `나중에` 버튼. `시작` 시 (데모용) 학습 완료로 처리: 진행 바 8/8, 현재 난이도 XP(기본 +120) 지급, 퀘스트 q1 자동 완료(+50), 토스트 "학습 완료! +120 XP". 버튼은 "오늘 학습 완료"로 비활성 |
| I5 | `난이도 바꾸기` 클릭 | 배지가 `쉬움 → 보통 → 어려움` 순환, 배지 색과 예상 XP(80/120/180) 변경, 토스트 "난이도를 '어려움'으로 바꿨어요" |
| I6 | 방 `참여` 클릭 | 인원 +1(가득 차면 `가득 참` 비활성), 버튼은 `참여 중`, 토스트 "'경영통계 퀴즈 배틀' 방에 들어갔어요" |
| I7 | `+ 친구 초대` 클릭 | 토스트 "초대 링크를 복사했어요" (실제 클립보드 복사는 시도만, 실패해도 토스트 표시) |
| I8 | 랭킹 `우리반`/`전체` 전환 | 목록 데이터 교체, 선택 탭 강조, `aria-selected` 갱신 |
| I9 | 하단 탭 클릭 | 활성 탭 변경. 홈 외 탭은 토스트 "'대결' 화면은 준비 중이에요" (홈 화면은 그대로) |
| I10 | 알림 종 클릭 | 빨간 점 사라짐, 토스트 "새 알림 2개: 박서준님이 대결을 신청했어요 외 1개" |
| I11 | 과목 카드 클릭 | 토스트 "'파이썬 기초' 강의실로 이동해요" |

공통: 토스트는 화면 하단(탭바 위)에 2.2초 표시 후 사라짐, 동시에 하나만. 모달은 배경 클릭·`Esc`·닫기 버튼으로 닫힘. 모든 상태는 메모리에만(새로고침 시 초기화). `prefers-reduced-motion`이면 애니메이션 생략.

## 7. 구현 규칙

- 파일: `index.html`, `css/style.css`, `js/app.js`. 빌드 없음, 프레임워크 없음, 더블클릭으로 열림(모듈 `type="module"` 사용 금지 — `file://`에서 막힐 수 있음, 일반 `<script defer>` 사용).
- `<html lang="ko">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`, `<title>누니 · 홈</title>`.
- 시맨틱 태그: `header`, `main`, `section`(각 `aria-labelledby`), `nav`. 클릭 요소는 모두 `<button>`.
- 목록(퀘스트, 친구, 방, 랭킹, 과목)은 JS가 목업 데이터로 렌더링.
- 터치 영역 최소 44×44px. 포커스 표시(`:focus-visible` 3px 코발트 외곽선).

## 8. QA 인수 체크리스트

- [ ] `index.html` 더블클릭(file://)으로 열었을 때 콘솔 오류 0개.
- [ ] 390px 폭에서 페이지 가로 스크롤 없음 (`document.documentElement.scrollWidth <= 390`). 과목 리스트만 내부 가로 스크롤.
- [ ] 320px, 1280px 폭에서도 레이아웃이 깨지지 않음. 데스크톱에서는 가운데 정렬된 폰 폭 열.
- [ ] 모든 UI 문구가 한국어이며 한글이 깨지지 않고 Pretendard(실패 시 대체 글꼴)로 표시됨. 단어 중간 줄바꿈 없음.
- [ ] 섹션 7개(헤더, 오늘의 맞춤 학습, 퀘스트, 친구, 랭킹, 과목, 탭바)가 순서대로 존재.
- [ ] 첫 화면 값: `Lv.7`, `1,240 / 1,500 XP`, 연속 `12일`, 코인 `340`, 퀘스트 `2/4 완료`.
- [ ] I1~I11 각 동작이 표대로 반응함 (모든 버튼이 클릭 시 눈에 보이는 결과를 냄).
- [ ] XP 계산 시나리오(난이도 보통 유지): 학습 시작(+120, q1 자동 +50) → 1,410 → q2 완료(+40) → 1,450 → 보너스 상자(+100, 코인 390) → 1,550 ⇒ `Lv.8` 모달, 바에는 `50 / 1,500 XP` 표시(이월). 다음 레벨 필요 XP는 1,500으로 고정.
- [ ] 랭킹 토글 시 목록이 바뀌고 `aria-selected`가 올바름. 전체 탭에 "내 순위 27위" 표시.
- [ ] 하단 탭 활성 표시가 클릭한 탭으로 이동. 탭바가 본문 내용을 가리지 않음.
- [ ] 글자 대비: 본문·보조 글자 4.5:1 이상, 큰 숫자·배지 3:1 이상 (탱저린 위 글자는 잉크색).
- [ ] 키보드만으로 모든 버튼 접근 가능, 포커스 표시가 보임, `Esc`로 모달 닫힘.
- [ ] 외부 리소스는 폰트 CDN뿐. 프레임워크·빌드 도구 없음.
