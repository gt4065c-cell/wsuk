## 0. 핵심 생각 3가지

1. **틀은 하나, 내용만 바뀐다.** 모든 강은 "입구 → 도입 대화 → 업무 2~5개 → 업무 평가 → 보상·지도" 5칸 순서가 같습니다. 학습자는 2강부터 "어디를 누르면 되는지" 이미 압니다.
2. **조작은 10종이면 30강을 다 덮는다.** 강의 내용은 대부분 "나누기·잇기·순서·틀린 곳·고르기·빈칸·대화·넘기기·건네기·만들기" 중 하나로 바꿀 수 있습니다. 부품마다 맞음/틀림 반응과 접근성이 미리 들어 있어서, 강을 만드는 사람은 내용만 적습니다.
3. **루키는 강이 끝날 때마다 변한다.** 레벨 숫자는 "수료한 강 수"와 정확히 같고(Lv.7 = 7강 수료), 부(部)가 끝날 때마다 겉모습이 한 단계씩 바뀝니다(7단계). 바뀐 모습은 친구에게 보낼 카드가 됩니다.

### 1-2. 게임 화면의 5개 칸 (위에서 아래로)

```
┌──────────────────────────────────┐
│ [Lv.3] 3강 진행 ███████░░  카드 2/4 │ ← ① 상단 막대(52px, 위에 고정)  [✕ 나가기]
│ [업무 2/4] 예시로 배우기   머신러닝 │ ← ② 업무 머리줄(28px)
│            (루키 96px)             │
│  ┌────────────────────────────┐   │ ← ③ 루키 무대: 루키 + 말풍선(2줄 이내)
│  │루키  규칙 대신 예시를 잔뜩   │   │
│  │      보여 주세요!            │   │
│  └────────────────────────────┘   │
│ ┌──────────────────────────────┐ │ ← ④ 작업판(부품 1개가 들어가는 자리, 길이 가변)
│ │  (분류 끌기 / 짝 맞추기 …)    │ │
│ └──────────────────────────────┘ │
│ [ 팀장 | 좋아, 예시 보여 줄게 ]    │ ← ⑤ 행동칸(아래 고정): 답 버튼·다음·확인
└──────────────────────────────────┘
```

- ① 상단 막대: 레벨 딱지 / 이 강 진행 막대(단계 기준: 도입·업무들·평가) / 이 강에서 받은 카드 수 / **[✕ 나가기]**(44px, 누르면 "여기까지 저장했어요" 후 지도로). 시제품에는 나가기가 없었음 → 추가.
- ② 업무 머리줄: 보라 딱지 "업무 k/n" + 업무 이름 + 오른쪽 청록 글자 개념 이름(강의 용어).
- ③ 루키 무대: 말풍선은 `role="status"`(화면 읽기 프로그램이 새 말을 읽어 줌). 말풍선 왼쪽 위 검정 딱지 "루키".
- ④ 작업판: 부품이 그려지는 유일한 자리. 부품은 이 칸 밖을 건드리지 않음.
- ⑤ 행동칸: 팀장 답 버튼(왼쪽에 파란 "팀장" 딱지, 글은 오른쪽 정렬 = "내가 말한다"는 느낌), [다음 ▶], 부품의 [다 놓았어요] 같은 확인 버튼.

### 1-3. 글 길이 원칙 (말풍선 2줄)

360px 휴대폰에서 말풍선 안쪽 폭은 약 298px, 17px 굵은 한글은 한 줄에 약 17자가 들어갑니다. 그래서:

| 자리 | 한 줄 최대 | 최대 줄 수 | 적는 법 |
|---|---|---|---|
| 루키 말풍선 | **16자**(띄어쓰기 포함) | **2줄** | 줄바꿈 위치를 데이터에 `|`로 직접 적음 → `"첫 업무는 학생 문의 나누기!|규칙표대로만 할게요."` |
| 팀장 답 버튼 | 18자 | 1줄 | `"r":"맞아, 규칙을 하나 더 넣어 줄게"` |
| 질문 줄(노란 글자) | 20자 | 1줄 | `"prompt":"루키가 왜 놓쳤을까? 알려 주세요"` |
| 보기·카드 글 | 18자 | 2줄 | 길면 카드 위 작은 글(14px)로 나눔 |
| 개념 메모(작업판 아래 쪽지) | 22자 | 2줄 | 강의 용어 풀이는 여기 한 번만 |
| 업무 평가 문항 | 제한 없음(공통 문항 원문 유지) | 권장 4줄 | 평가는 시험지 공정성 우선 |

- 말풍선 2줄을 넘길 이야기는 **말풍선을 2개로 나누고** 팀장 답 버튼을 사이에 끼웁니다. "읽기만 하는 긴 글"은 만들지 않습니다.
- 강의 설명이 길어야 하면 말풍선이 아니라 **능력 카드 3줄**(보상 화면)로 옮깁니다. 거기가 복습 자리입니다.
- 앱 개발자의 데이터 검사기(지금 `app/tools/build_data.py` 자리)에 위 숫자를 넣어 **강 데이터를 저장할 때 자동으로 글 길이를 검사**하게 합니다. 사람이 세지 않습니다.

## 2. 한 강(스테이지) 표준 흐름

```
[0 입구] → [1 도입 대화] → [2 업무 1 … 업무 n (n=2~5)] → [3 업무 평가] → [4 보상·지도]
   10초        30초              업무당 1~2분                 1~2분           30초
                                                             → 한 강 6~10분 목표
```

### 2-0. 입구 (스테이지 표지) — "3초 안에 오늘 할 일"

```
        [ 3강 · 루키의 첫 보고서 ]        ← 초록 테두리 알약 딱지
     오늘 루키에게 가르칠 일은
        '요약하기'                      ← 28px, 핵심 낱말만 색 번짐
   (루키 170px, 둥실둥실 떠 있음)
 ┌─────────────────────────────┐
 │ 내 루키     삐삐 · Lv.2 사원증 │
 │ 오늘 할 일   업무 4개 + 평가 3 │
 │ 걸리는 시간  약 7분            │
 │ 친구 소식    팀원 2명이 깼어요  │  ← 점수 없이 인원만
 └─────────────────────────────┘
 [        출근하기 ▶        ]          ← 화면 맨 아래 주 버튼
```
- 이어 하기가 있으면 주 버튼이 **[업무 3부터 이어 하기 ▶]**, 그 아래 글자 버튼 [처음부터].
- 1강에서만: 출근 전 **루키 이름 짓기**(빈칸 1개, 8자 이내, 기본값 "루키"). 애착이 생기고 공유 카드에 실명 대신 쓰임.

### 2-1. 도입 대화 (2~4말풍선)

- 목적: 이번 강의 **핵심 질문을 루키가 곤란해하며 던진다**. (예: "학습 기록이 제 머릿속엔 없어요!")
- 형식: 루키 말풍선 → 팀장 답 버튼 1개(분위기용) 반복. 마지막 말풍선은 첫 업무로 넘어가는 말.
- 규칙: 강의 용어는 도입에서 설명하지 않고, 업무 안에서 "해 본 다음" 한 번만 이름 붙임(문제 먼저 → 이름 나중).

### 2-2. 업무 (2~5개) — 업무 하나의 안쪽 순서

```
(a) 일 받기 대화 1~2개  →  (b) 부품 조작 1~2개  →  (c) 루키 반응·깨달음 대화 1~3개  →  (d) 능력 카드 받기
```
- (b)에는 부품 1개가 기본, 많아야 2개(예: 시제품 업무 2 = 작동 보기 + 틀린 곳 찾기 + 대화 선택).
- **연습이라 몇 번이고 다시 할 수 있음.** 틀려도 막히지 않음(아래 3-0 "틀림 3단계"). 업무 결과는 평가 점수에 들어가지 않고, "처음에 맞혔는지" 기록만 맞춤학습(눈높이) 쪽으로 넘김.
- (d) 능력 카드 받기: **반 화면 짧은 연출**(카드가 뒤집히며 나타남, 약 1.5초) + [카드 받기 ✓]. 
  - 시제품은 업무마다 "LEVEL UP Lv.1→2"를 띄웠는데, 그러면 1강만 끝나도 Lv.6이 되어 30강이면 숫자가 의미 없어집니다(교훈노트: 이름=실제 의미). → **업무 끝 = 카드 획득, 강 끝 = 레벨 업**으로 나눕니다. 큰 폭죽 연출은 강 끝에 한 번.

### 2-3. 업무 평가 (공통 문항 3개)

```
 [평가] 루키의 업무 평가   3강 문제 3개
 (루키: "평가관이 왔어요! 떨려요…|같이 풀어 주세요.")
 ┌ 업무 평가 1/3 ─────────────────┐
 │ 문항 글(19px)                    │
 │ (A) 보기   (B) 보기 …  56px 이상  │
 └──────────────────────────────┘
  → 고르면 즉시: 정답에 ✓, 내가 고른 오답에 ✗, 해설 1~2문장, (오해 보기를 골랐으면) "자주 하는 실수" 한 줄
  [다음 문제 ▶]
```
- **고르기 부품의 "평가 모드"**를 씀(3-5). 한 번만 고를 수 있고, 다시 고를 수 없음.
- 평가 문항은 강마다 공통(모두 같은 문항) — 교훈노트 "연습과 평가 분리" 그대로.
- 결과: 별 0~3개. **별이 0개여도 수료**(루키는 승진함). 대신 지도 칸에 "↺ 복습 추천" 표시.

### 2-4. 보상·지도 (강 끝)

순서: **① LEVEL UP 연출 → ② (승진 강이면) 승진식 → ③ 오늘의 루키 카드 + [공유] → ④ 30강 지도 → ⑤ 오늘의 미션 → ⑥ [다음 강 시작]**

```
① LEVEL UP!  Lv.2 → Lv.3       (폭죽 26조각, 2.4초, 움직임 줄이기 설정이면 폭죽 없음)
   (루키 120px 깡충)
   [이 강 핵심 카드 — 금 테두리]
   [카드 받기 ✓]
② 승진식 (부 마지막 강에서만): 이전 모습 → 새 모습 나란히, "사원증 → 헤드셋" + 새 장식 이름
③ 🎉 3강 클리어!  — 루키 카드(5-3) + [내 루키 카드 공유] (금색 버튼)
④ 30강 지도 (5-1)
⑤ 오늘의 미션: 내 일에 적용해 보는 과제 1개 (2줄 + 예시 1줄)
⑥ [4강 시작하기] (주 버튼)  / [처음부터 다시 하기] (보조)
```

## 3. 조작 부품 10종

### 3-0. 모든 부품이 똑같이 지키는 약속

**(1) 데이터 공통 칸** — 모든 부품 JSON에 들어가는 칸

```json
{
  "id": "L01-T5-P1",
  "type": "sort",
  "prompt": "카드를 알맞은 상자로",
  "say": { "t": "카드를 알맞은 상자에|넣어 주세요. 빨리요!", "m": "happy" },
  "okSay": { "t": "딩동! 맞아요.|남은 카드 {left}장!", "m": "happy" },
  "doneSay": { "t": "다 넣었어요!", "m": "happy" },
  "hint2": "상자 이름을 다시 읽어 봐요",
  "level": { "easy": { "items": 3 }, "hard": { "items": 6 } }
}
```
- `m`(루키 표정): `normal`·`happy`·`confused`·`think` 4가지 중 하나.
- `level`: 수준(눈높이)에 따라 항목 수·힌트를 바꾸는 칸. 실제 규칙은 맞춤학습 설계자가 정하고, 디자인은 "개수가 바뀌어도 화면이 안 깨지게"만 보장.
- 부품이 끝나면 앱에 남기는 기록: `{ id, firstTry: 처음에 맞혔나, tries: 시도 수, sec: 걸린 초 }` — 점수 아님, 맞춤학습 재료.

**(2) 맞음 반응(모든 부품 같음)**
- 항목에 **청록 + ✓**, 짧게 반짝(0.7초), 루키 `happy` + 깡충, 휴대폰 진동 30ms(지원할 때만), 효과음은 기본 꺼짐.
- 처음에 맞히면 **+XP 글자가 위로 떠오름**, 연속으로 처음에 맞히면 상단에 **콤보 딱지**("2콤보", B안에서 가져옴). 콤보가 끊겨도 꾸중 문구 없음(조용히 사라짐).

**(3) 틀림 반응 — "틀림 3단계" (절대 막히지 않게)**

| 몇 번째 틀림 | 반응 |
|---|---|
| 1번째 | 항목 **좌우 흔들림 + 주홍 테두리**(제자리로 돌아옴), 루키 `confused` + 그 보기 전용 힌트 말풍선(`fb`) |
| 2번째(같은 항목) | 더 직접적인 힌트(`hint2`) + 맞는 자리(상자·줄)가 노란 점선으로 1초 깜빡 |
| 3번째 | 루키가 "같이 해 봐요!" 하며 **정답 자리로 자동으로 옮겨 줌**, ✓ 대신 "함께 ✓" 표시. 기록은 `firstTry:false` |

- 틀린 보기는 **다시 누를 수 없게 흐리게(투명도 85%) + ✗**. 정답 보기를 지우지 않음.
- 틀렸을 때 "땡", 빨간 화면 번쩍, 점수 깎기 연출은 쓰지 않음(연습이니까).

**(4) 접근성(모든 부품 같음)**
- **색 + 기호**: 맞음 ✓, 틀림 ✗, 새로 생긴 것 ★, 놓을 곳 점선. 색이 안 보여도 기호로 구분.
- **끌기에는 반드시 "누르고-누르기" 대안**: 카드를 한 번 누르면 노란 테두리(선택됨) → 놓을 곳을 누르면 놓임. 시제품 `dragSetup` 방식 그대로 부품 공통 기능으로 만듦.
- 손가락이 8px 넘게 움직여야 끌기로 인식(그냥 누름과 구분). 끄는 중인 카드는 1.04배 + 그림자, 놓을 곳은 청록으로 커짐.
- 화면 읽기 프로그램: 끌 카드·놓을 곳 모두 버튼 역할(`role="button"`, "상자: 생성, 0장" 같이 이름). 결과는 말풍선으로 읽힘.
- 시간 재기는 **보여 주기만**(실패 없음). 설정에서 끌 수 있음. 시제품 업무 5의 "빨리요!" 타이머도 실패 조건 없음 유지.
- "움직임 줄이기" 설정이면 흔들림·폭죽·깡충 대신 테두리 색 + 기호만.
- 글자 크기 200%에서 카드가 세로로 늘어나도 겹치지 않게(고정 높이 금지, `min-height`만).

### 부품 4. 틀린 곳 찾기 (`spot`) — "루키 실수 잡아내기"

```
 ┌ 팀장이 준 강의 메모 ─────────────┐   ← 비교 자료(ref): 노란 쪽지, 선택
 │ AI 연구는 1956년 다트머스 …      │

 │ 정답: 1956년                     │
 │ 해설: 다트머스 모임이 출발점이에요  │
 │ 해설: 첫 AI 로봇이 완성됐어요      │ → 누르면 취소선 + "✗ 메모에 없음"
 └───────────────────────────────┘
   메모와 비교해서, 메모에 없는 줄을 눌러 주세요
```
- 언제 쓰나: AI가 지어낸 말 찾기, 잘못 분류한 줄, 코드 오류 줄, 위험한 권한, 개인정보가 들어간 줄.
- 표시 방식(`show`): `"lines"`(글 줄) / `"rows"`(왼쪽 글 + 오른쪽 결과 딱지, 업무 2 방식) / `"code"`(고정폭 글꼴, 줄 번호).
- 줄이 하나씩 타자 치듯 나타나게 할 수 있음(`typing: true`, 줄당 0.6초) — "루키가 쓰는 중" 연출.

```json
{
  "type": "spot", "show": "lines", "typing": true,
  "ref": { "label": "팀장이 준 강의 메모", "t": "AI 연구는 1956년 다트머스 연구 모임에서 본격적으로 시작됐다." },

    { "t": "문제: AI 연구가 본격적으로 시작된 해는?" },
    { "t": "정답: 1956년" },
    { "t": "해설: 다트머스 연구 모임이 출발점이에요." },

```

- 언제 쓰나: 코드 한 줄 완성(2부 퀴즈게임 만들기), 프롬프트 문장 완성, 개념 정의 문장 완성.
- `display`: `"code"`(고정폭, 줄 번호) / `"sentence"`(일반 문장).
- 조작: 조각을 빈칸으로 끌기 **또는 조각 누르기 → 빈칸 누르기**. 빈칸이 하나면 조각만 눌러도 들어감. 들어간 조각을 다시 누르면 빠짐.

```json
{
  "type": "fill", "display": "code",
  "prompt": "루키의 코드에 빠진 낱말을 채워 줘요",
  "text": "{1} i in range(3):\n    print(\"문제\", i)",
  "blanks": [ { "id": 1, "ans": ["for"] } ],
  "chips": ["for", "if", "print"],
  "fb": { "if": "if는 '만약'이에요.|반복은 다른 낱말!" },
  "check": "auto"
}
```
- `check`: `"auto"`(빈칸이 다 차면 바로 채점) / `"button"`([확인] 누르면 채점, 빈칸 3개 이상일 때).
- 맞음: 빈칸 테두리 청록 + ✓, (코드면) 아래 **작동 보기**(보조 부품)로 실행 결과가 한 줄씩 찍힘 — "고친 코드가 돌아간다"는 손맛.
- 틀림: 조각이 튕겨 나와 제자리, 빈칸 ✗ 잠깐 표시.
- `ans`는 여러 개 허용(띄어쓰기·같은 뜻 낱말).

### 부품 7. 대화 선택 (`reply`) — "팀장으로서 대답하기"

```
 (루키: "그럼 이제 규칙 카드는|버려도 돼요?")
 팀장님의 판단은?
 [ 팀장 |        응, 이제 필요 없어. 버리자 ]   ← 행동칸의 팀장 답 버튼 2~3개
 [ 팀장 |       아니, 일에 맞게 같이 골라 써 ]
```
- **고르기(5)와 다른 점**: 자료를 보고 정답을 고르는 게 아니라, **루키와의 대화에서 판단·태도를 정함**. 보기가 작업판이 아니라 **행동칸(아래)**에 팀장 말투로 나옴. 고른 말에 따라 루키가 되묻거나 이야기가 이어짐.
- 언제 쓰나: "옛 기술 버릴까?", "이대로 수업에 써도 될까?", "권한 다 줄까?" 같은 판단, 윤리·안전 태도.

```json
{
  "type": "reply",
  "say": { "t": "그럼 이제 규칙 카드는|버려도 돼요?", "m": "normal" },
  "prompt": "팀장님의 판단은?",
  "opts": [
    { "r": "응, 이제 필요 없어. 버리자", "then": { "t": "정말요? 조건이 분명한|일엔 정확했는데…", "m": "confused" } },
    { "r": "아니, 일에 맞게 같이 골라 써", "ok": true, "then": { "t": "옛 기술도 버리지 않고|골라 쓰는 거군요!", "m": "happy" } }
  ]
}
```
- 맞음: 버튼 ✓ 후 0.65초 뒤 `then` 말풍선, 다음으로. 틀림: 그 버튼 ✗ + 흐림, 루키 `then`(되묻기) → 남은 버튼 중 다시 고름.
- 정답이 없는 대화(분위기용)는 `ok`를 모두 `true`로 → 고른 말에 따라 루키 대답만 달라짐(갈래 대화).
- 답 버튼은 18자 1줄. 오른쪽 정렬 + 왼쪽 "팀장" 딱지(색이 아니라 글자로 "내 말"임을 표시).

### 부품 8. 타임라인 넘기기 (`swipe`) — "카드 옆으로 넘기며 보기"

출처: **B안 타임라인 카드 + 콤보**.

```
  ● ● ○ ○ ○ ◆ ○            ← 위치 점(◆ = 퀴즈 카드, 모양으로 구분)
 ┌──────────────────────┐
 │       (그림 SVG)       │
 │   1956                 │  ← 큰 숫자/제목
 │   다트머스 연구 모임    │
 │   "생각하는 기계를       │
 │    만들어 보자!"        │  ← 한 줄 설명 2줄 이내
 └──────────────────────┘
   [◀ 이전]      [다음 ▶]      ← 밀기 대안 버튼(56px)
   ← 옆으로 밀어서 넘겨요 (첫 카드에서만)
```
- 언제 쓰나: 역사·변화 흐름, 한 과정의 단계 소개, 사례 여러 개 훑기. **루키가 "공부하는" 장면**(루키 무대는 작게 접고 카드가 주인공).
- 사이사이 **퀴즈 카드**(`quiz`): 안에 고르기/분류 끌기 미니판. 풀어야 다음으로 넘어감(잠금 = ▶ 버튼에 자물쇠 + "퀴즈를 풀면 열려요").
- 콤보: 퀴즈 카드를 처음에 맞히면 연속 콤보 딱지. 업무 끝 화면에 "최고 n콤보".

```json
{
  "type": "swipe",
  "cards": [
    { "art": "dartmouth", "big": "1956", "t": "다트머스 연구 모임", "s": "생각하는 기계를|만들어 보자!" },
    { "art": "rulebook",  "big": "규칙", "t": "규칙 중심 AI", "s": "사람이 규칙을|하나하나 넣어요" },
    { "quiz": { "type": "pick", "mode": "practice", "prompt": "규칙 AI의 약점은?",
                "opts": [ { "t": "규칙에 없는 말을 놓침", "ok": true }, { "t": "계산이 느림", "fb": "속도 문제가|아니에요!" } ] } },
    { "art": "examples",  "big": "예시", "t": "머신러닝", "s": "예시를 보고|패턴을 찾아요" }
  ],
  "combo": true
}
```
- 맞음/틀림: 퀴즈 카드 안의 부품 규칙을 따름. 넘기기 자체엔 맞고 틀림 없음.
- 접근성: **밀기는 반드시 [◀][▶] 버튼으로도 가능**. 위치 점은 크기·모양(●○◆)으로 구분. 카드 그림에는 `alt`.
- 카드 3~8장 + 퀴즈 카드 1~3장.

### 부품 9. 루키에게 건네기 (`give`) — "도구·자료·권한을 골라 주기"

출처: C안 업무 4(열쇠 3개 중 하나를 루키에게).

```
 ┌ 오늘의 일: 학생 A에게 맞는 다음 문제 고르기 ┐
 │ ┌ - - - - - - - - - - - - - - - - - - ┐ │
 │ ╎ (루키 56px)  여기로 끌어다 놓기          ╎ │ ← 놓을 곳 = 루키(파란 점선)
 │ ╎             또는 열쇠를 누른 뒤 여기를 눌러요╎ │
 │ └ - - - - - - - - - - - - - - - - - - ┘ │
 │ [🗝 모든 자료 창고 마스터키  무엇이든 다 열 수 있음] │
 │ [🔑 학습 기록 보기 도구      허락받은 기록만 보기 ] │ ← 끌 카드(56px), 이름 + 작은 설명
 │ [✏ 성적 고치기 권한         점수를 바꿀 수 있음  ] │
 └──────────────────────────────────────┘
```
- 언제 쓰나: 도구·권한 고르기(최소 권한), 기억 창고(자료)에 넣을 자료 고르기, 루키에게 줄 예시 자료 고르기, 프롬프트에 넣을 정보 고르기. **3부(기억 창고·출입증), 5부(도구 가방)에 자주 씀.**
- 받은 뒤 **작동 보기**(보조 부품)로 루키가 그 도구를 쓰는 기록이 한 줄씩 찍힘(`after`).

```json
{
  "type": "give",
  "task": "학생 A에게 맞는 다음 문제 고르기",
  "say": { "t": "기록을 볼 열쇠를|딱 하나만 건네주세요!", "m": "normal" },
  "items": [
    { "k": "all",  "icon": "key-gold", "t": "모든 자료 창고 마스터키", "s": "무엇이든 다 열 수 있음", "fb": "너무 커요! 필요 없는|것까지 다 열잖아요." },
    { "k": "ok",   "icon": "key",      "t": "학습 기록 보기 도구",     "s": "허락받은 기록만 보기",   "ok": true },
    { "k": "edit", "icon": "pencil",   "t": "성적 고치기 권한",        "s": "점수를 바꿀 수 있음",   "fb": "다음 문제 고르는 데|성적은 필요 없어요!" }
  ],
  "need": 1,
  "after": { "type": "log", "lines": ["▶ 학습 기록 보기 도구 실행 (학생 A)", "◀ 받은 정보: 생성과 검증 구분이 약함", "✔ 다음 문제: \"지어낸 문장 찾기\" 선택"] }
}
```
- 맞음: 카드가 루키 쪽으로 빨려 들어가고 작은 루키 `happy`. 여러 개 건네기(`need: 2~3`)면 "건넨 것 1/2".
- 틀림: 카드가 루키 앞에서 **튕겨 나옴**(흔들림) + 루키 `confused` + `fb`. 받을 수 없는 이유를 루키가 말함.
- 학생 이름은 늘 "학생 A(가짜 학생)"처럼 가짜로.

### 부품 10. 미니 만들기 (`build`) — "조각을 조립해 루키 결과물 완성"

```
 루키가 낼 퀴즈 1문제를 만들어 줘요
 ┌ 완성판 ──────────────────────┐
 │ 질문    [ 여기에 조각 놓기    ] │  ← 빈 틀(슬롯) 2~4개, 이름표 붙음
 │ 정답    [ 1956년             ] │
 │ 틀린 보기[                    ] │
 └──────────────────────────────┘
 조각: (AI 연구가 시작된 해는?) (1956년) (1991년) (첫 AI 로봇 완성) …
 [ 루키에게 맡기기 ▶ ]   ← 행동칸: 다 채우면 켜짐
```
- 언제 쓰나: 프롬프트 조립(역할·할 일·조건·출력 형식), 퀴즈 문항 만들기, 간단한 화면/규칙 만들기, 강 마지막 "오늘 배운 걸로 직접 만들어 보기". **2부(퀴즈게임 만들기)의 대표 부품.**
- 빈칸 채우기(6)와 다른 점: 정답이 하나가 아닐 수 있음. **조건만 맞으면 통과**(`rule`), 그리고 결과를 **루키가 실제로 실행해 보여 줌**(작동 보기) → 만든 것이 돌아가는 손맛.

```json
{
  "type": "build",
  "goal": "루키가 낼 퀴즈 1문제를 만들어 줘요",
  "slots": [ { "id": "q", "label": "질문" }, { "id": "a", "label": "정답" }, { "id": "w", "label": "틀린 보기" } ],
  "parts": [
    { "id": "p1", "t": "AI 연구가 시작된 해는?", "fit": ["q"] },
    { "id": "p2", "t": "1956년", "fit": ["a"] },
    { "id": "p3", "t": "1991년", "fit": ["w"] },
    { "id": "p4", "t": "첫 AI 로봇 완성", "fit": [], "trap": "메모에 없는 말이에요!|넣으면 안 돼요." }
  ],
  "rule": "every-slot-fits",
  "run": { "type": "log", "lines": ["▶ 루키가 문제를 냈어요", "◀ 친구 루키 '토토'가 풀었어요: 정답!", "✔ 문제 1개 완성"] },
  "result": { "kind": "card", "title": "루키의 첫 문제" }
}
```
- 맞음: [루키에게 맡기기] → 루키 `think`(전구 빨리 깜빡) → 작동 보기 → 완성된 결과물이 작은 카드로 튀어나옴(이 카드는 공유 카드에도 쓸 수 있음).
- 틀림: 맞지 않는 칸에 놓으면 그 조각만 튕겨 나옴. 함정 조각(`trap`)은 루키가 이유를 말함. [루키에게 맡기기] 눌렀는데 조건이 안 맞으면 루키가 "질문 칸이 비었어요!"처럼 **어느 칸인지 짚어 줌**(그 칸 노란 점선).
- 접근성: 빈 틀마다 이름표 글자, 조각은 누르기-누르기 가능.

## 4. 루키 캐릭터 규격

### 4-1. 레벨과 겉모습 — 숫자와 의미를 맞춤

- **레벨 = 수료한 강 수.** 시작은 Lv.0, 1강 수료 Lv.1 … 30강 수료 Lv.30. (시제품의 "업무마다 레벨 업"은 "업무마다 카드 획득"으로 바꿈 — 2-2 참고)
- **겉모습 단계 = 직급 7단계.** 부(部)를 마칠 때 승진(1강은 첫 성공 경험을 위해 특별히 1단계 승진).

| 단계 | 직급 이름 | 언제 | 몸 색 | 대표 장식(모양으로 구분) |
|---|---|---|---|---|
| 1 | 새내기 | 시작(Lv.0) | 회색 `#9AA8BF` | 머리 위 안테나 + 깜빡이는 전구. 장식 없음 |
| 2 | 사원증 | 1강 수료 | 하늘 `#7FB3FF` | 가슴에 흰 명찰 "ROOKIE" |
| 3 | 헤드셋 | 5강(1부 끝) | 파랑 `#5B8CFF` | 머리를 감싼 헤드셋 + 입 옆 마이크 |
| 4 | 메이커 | 13강(2부 끝) | 남보라 `#8D84FF` | 오른손 노란 펜 + 볼에 별 스티커 |
| 5 | 기억 관리자 | 21강(3부 끝) | 보라 `#A676FF` | 등 뒤 작은 배낭(기억 창고) + 목걸이 출입증 |
| 6 | 튜터 | 25강(4부 끝) | 청록 `#3FC1C9` | 학사모(안테나 대신) + 술 장식 |
| 7 | 파트너 | 30강(5부 끝) | 금색 `#FFB547` | 허리 도구 벨트 + 가슴 금 별 배지 |

- 승진 강 번호는 이야기 지도가 확정되면 그 부의 마지막 강으로 맞춤.
- 단계는 **색만이 아니라 장식 모양으로** 구분(색약 학생도 구분). 작은 크기(40px)에서도 보이게 장식은 최소 8px 덩어리.
- **장식이 쌓여 지저분해지지 않게**: 화면에는 "명찰 + 지금 직급 대표 장식"이 기본. 이전 장식은 **옷장**에 보관하고, 학습자가 최대 3개까지 골라 낄 수 있음(꾸미기 = 보상, 친구와 구분됨).

#### 겉모습 바꾸는 방식 — A안(추천) / B안

| | A안 장식 추가형 (추천) | B안 몸 모양 진화형 |
|---|---|---|
| 방법 | 몸 모양은 그대로, 색 + 장식만 바뀜 | 단계마다 머리·몸 모양 자체가 바뀜(작은 로봇 → 큰 로봇) |
| 장점 | 그림 1벌 + 장식 7개로 끝 → 빠르고 품질 일정. "내 루키"라는 정체성이 유지됨. 옷장 꾸미기 가능 | 변화가 크고 극적 |
| 단점 | 변화가 B보다 덜 극적 → 승진식 연출로 보완 | 그림 7벌, 표정 4종 × 7 = 28벌 관리. 강 제작 속도 목적과 어긋남 |

### 4-2. 표정 4종 (모양으로 구분, 색은 같음)

| 표정 (`m`) | 눈 | 입 | 몸짓 | 쓰는 때 |
|---|---|---|---|---|
| `normal` 보통 | 세로 타원 2개, 4초마다 깜빡 | 작은 미소 곡선 | 없음 | 설명, 질문 |
| `happy` 기쁨 | 위로 볼록한 ∩ 반달 2개 | 큰 미소 곡선 | 깡충(0.5초) | 맞음, 카드, 칭찬 |
| `confused` 헷갈림 | 한쪽 큰 동그라미 + 한쪽 일자 (짝눈) | 물결 입 | 좌우 흔들림 + 머리 옆 노란 **?** | 틀림, 막힘, 루키 실수 |
| `think` 생각 중 | 눈동자가 오른쪽 위로 쏠린 작은 타원 | 일자 입 | 전구 빨리 깜빡 + 머리 옆 점 3개 "…" 차례로 | 공부 중, 쓰는 중, 도구 실행 중 |

- 시제품의 `think`는 전구만 빨리 깜빡여서, 안테나가 없는 6단계(학사모)에서는 안 보였음 → **눈 모양 + 점 3개**를 추가해 어느 단계에서도 보이게.
- "자랑"이나 "슬픔" 표정은 만들지 않음(4종 고정 — 데이터 쓰는 사람이 고민하지 않게). 레벨 업 장면은 `happy` + 큰 깡충.

### 4-3. SVG로 그리는 규칙 (개발자용, 쉬운 풀이 포함)

SVG는 "점과 선 좌표로 그리는 그림 파일"입니다. 크게 해도 깨지지 않고, 색을 코드로 바꿀 수 있어 루키에 맞습니다.

1. **그림판 크기 고정**: `viewBox="0 0 120 124"`(가로 120 · 세로 124 칸). 모든 장식은 이 칸 안의 정해진 자리에만 그림.
2. **그리는 순서(뒤 → 앞)** 고정:
   `등 장식(배낭)` → `안테나` → `귀 2개` → `머리` → `얼굴 화면` → `눈(표정별 4묶음)` → `입(표정별)` → `? 표시·점 3개` → `손 2개` → `몸` → `가슴 장식(명찰·배지)` → `손 장식(펜)` → `머리 장식(헤드셋·학사모)`
3. **기본 몸 좌표**(시제품 그대로): 머리 `rect x20 y22 w80 h58 rx22`, 얼굴 화면 `rect x30 y33 w60 h36 rx13`, 귀 `x11/x98 y40 w11 h22`, 몸 `rect x34 y82 w52 h34 rx12`, 손 `circle (27,96) (93,96) r7`, 안테나 `(60,24)→(60,12)` + 전구 `r5`.
4. **장식 자리(구역)** — 장식은 자기 구역 밖으로 나가지 않음

| 구역 | 좌표 범위 | 들어가는 장식 |
|---|---|---|
| 머리 위 | y 0~24 | 안테나, 학사모 |
| 머리 둘레 | x 10~110, y 10~80 | 헤드셋 |
| 가슴 | x 43~77, y 86~102 | 명찰, 금 별 배지, 출입증 |
| 오른손 | x 88~112, y 76~104 | 펜 |
| 허리 | x 34~86, y 104~116 | 도구 벨트 |
| 등 뒤 | x 28~92, y 78~118 (몸 뒤에 먼저 그림) | 배낭 |
| 얼굴 옆 | x 92~120, y 4~40 | ? 표시, 점 3개 |

5. **색은 변수 하나로**: 머리·귀·몸·손은 모두 `fill: var(--rk)`. 단계는 `data-stage="1~7"`로 `--rk` 값만 바꿈. 얼굴 화면은 언제나 짙은 남색 `#1D2540`, 눈·입은 언제나 민트 `#7CF7D4`(대비가 커서 작아도 표정이 보임).
6. **표정·단계는 이름표(class)로 켜고 끔**: `class="rk"` + `data-mood="happy"` + `data-stage="3"` + 옷장 장식 `data-wear="badge headset"`. 그림 파일은 하나, 켜고 끄기만 함 → 그림 7×4=28벌이 아니라 1벌.
7. **선과 모양 규칙**: 선 두께 3~5(작게 쓸 장식도 2 이상), 선 끝 둥글게(`round`), 모서리 둥글게(rx 3 이상), 그림자·그라데이션 없음(납작한 그림), 쓰는 색은 위 7개 몸 색 + `#1D2540` `#7CF7D4` `#FFD166` `#4FE3C1` `#FFFFFF` `#2B3560`만.
8. **크기 4가지만 사용**: 입구 170px / 레벨 업 120px / 게임 무대 96px(낮은 휴대폰 64px) / 친구 얼굴 40px(머리만 그린 작은 그림 `viewBox 0 0 40 40`, 몸 색 + 눈만).
9. **그림 안에 글자 넣지 않기**(예외: 명찰 "ROOKIE" 하나). 루키 이름은 그림 밖 글자로.
10. **화면 읽기**: 그림은 `aria-hidden="true"`(장식), 대신 옆 글자에 "삐삐 · Lv.3 · 헤드셋 단계"처럼 상태를 글로 씀.
11. **움직임**: 둥실(3초), 깡충(0.5초), 흔들(0.45초), 깜빡(4초) 4가지만. "움직임 줄이기" 설정이면 모두 멈춤.

## 5. 강 바깥 화면

### 5-1. 30강 지도 — A안(추천) / B안

**A안 "루키 회사 빌딩" (추천)** — 세로로 올라가는 건물. 부 = 층, 강 = 층 안의 방(동그라미). 지그재그 길.

```
 ┌───────────── 5층 · 도구 가방 채우기 ───┐   ← 층 간판(부 이름), 잠긴 층은 흐림 + 🔒
 │        ○30   ○29                       │
 │   ○26     ○27    ○28                   │
 ├───────────── 2층 · 퀴즈게임 만들기 ─────┤
 │      ◎7  ← (루키 40px 서 있음, "여기!")  │   ← 지금 할 강: 보라 점선 + 숨쉬듯 커졌다 작아짐
 │   ✓6                                    │
 ├───────────── 1층 · 일 맡기는 법 ────────┤
 │ ✓5★★☆  ✓4★★★  ↺3★☆☆  ✓2  ✓1          │   ← 끝낸 강: 금색 + ✓ + 별
 │        (친구 얼굴 2개가 6번 방에)         │   ← 친구 루키 얼굴 = 친구가 지금 있는 강
 └────────────────────────────────────────┘
   맨 아래 고정: [7강 이어 하기 ▶]
```
- 열면 **지금 할 강이 화면 가운데**에 오도록 자동 스크롤. 맨 아래 주 버튼은 늘 "지금 할 강".
- 칸(방) 크기 **56px**(누르기 쉬움). 상태는 **기호로 구분**: 끝냄 ✓, 지금 ◎ + 루키, 잠김 🔒, 복습 추천 ↺. 별(★☆)은 내 화면에만.
- 승진 강(5·13·21·25·30)은 **조금 큰 칸 + 다음 장식 그림자 미리 보기**("헤드셋까지 2강") → 다음 목표가 보임.
- 친구: 친구 루키 얼굴(40px)을 그 친구가 있는 칸 옆에. 누르면 "토토 · Lv.6" 이름과 레벨만(점수 없음).
- 끝낸 칸을 누르면: [다시 하기] [이 강 카드 보기].

**B안 "부 카드 목록"** — 시제품에 있던 모양. 부마다 카드 하나, 안에 강 번호 동그라미가 줄지어 있음.
- 장점: 한 화면에 30강이 다 보임, 만들기 쉬움. 단점: 길을 올라가는 "모험" 느낌이 약함, 칸이 34px이라 누르기 작음(B안을 고르면 44px로 키움).

### 5-2. 능력 카드

```
 ┌──────────────────────────┐   너비 280~320px, 둥글기 20px
 │ [아이콘 34px]    [핵심 카드] │   ← 등급 딱지(글자로 등급 표시)
 │ 일 구별하기                 │   ← 카드 이름 22px 아주 굵게 (루키가 할 줄 알게 된 일)
 │ 1강 핵심 · 수료 카드         │   ← 부제 14px: 강의 개념 이름
 │ ▸ 분류: 종류를 골라 나눠요   │
 │ ▸ 생성: 새로 만들어요        │   ← 핵심 3줄 (각 22자 이내) = 이 강의 복습 요약
 │ ▸ 도구 실행: 도구로 조회해요  │
 │                  1강 · 업무 5 │   ← 14px
 └──────────────────────────┘
```

| 등급 | 언제 | 모양 |
|---|---|---|
| 업무 카드 | 업무마다 1장 | 파스텔 그라데이션 바탕(업무 순서대로 5색 c1~c5), 테두리 없음 |
| 핵심 카드 | 강의 마지막 업무 | 위 + **금 테두리 2px** + 빛 지나가는 반짝 |
| 승진 카드 | 부의 마지막 강 | 위 + **무지갯빛 테두리** + 새 장식 그림 |

- 등급은 **딱지 글자**로도 씀(테두리 색만으로 구분 금지).
- 카드 이름은 "루키가 할 줄 알게 된 일"(동사형: 규칙 따르기, 패턴 찾기, 초안 쓰기) — 학습자가 "내가 가르쳐 준 것"으로 느끼게.
- **카드 지갑**(모은 카드 보기): 부별로 3열 격자. 카드를 누르면 뒤집혀서 **뒷면 = 확인 1문제**(고르기 부품, 연습 모드). → 모으는 재미가 곧 복습.
- 데이터:

```json
{ "id": "L01-C5", "lesson": 1, "task": 5, "grade": "core",
  "icon": "compass", "name": "일 구별하기", "sub": "1강 핵심 · 수료 카드",
  "pts": ["분류: 종류를 골라 나눠요", "생성: 새로 만들어요", "도구 실행: 도구로 조회해요"],
  "back": { "type": "pick", "mode": "practice", "prompt": "'해설 초안 쓰기'는?", "opts": [ { "t": "생성", "ok": true }, { "t": "분류", "fb": "새로 만드는|일이에요!" } ] } }
```

### 5-3. 오늘의 루키 카드 (결과 화면) & 공유 카드

**앱 안 루키 카드**(결과 화면, 시제품 `rkcard` 그대로 + 고칠 점)
- 남보라→청록 그라데이션 + 금 테두리 + 빛 지나감. 루키 92px + 루키 이름 + "Lv.3 · 헤드셋" + 업무 평가 별 + "오늘 루키가 배운 한 줄"(2줄) + 이 강 카드 아이콘 줄.
- 고칠 점: 시제품의 12~13px 글자(카드 아이콘 이름 11.5px, 작은 설명 12.5px)를 **14px로** 올림.

**공유 카드(이미지로 저장·단톡방 보내기)**

```
 ┌──────── 1080 × 1350 px (세로 4:5) ────────┐
 │ 레벨업 캠퍼스                  3강 클리어   │  ← 위 띠
 │                                          │
 │            (루키 그림, 폭의 45%)           │
 │                                          │
 │          삐삐  ·  Lv.3 · 헤드셋             │  ← 루키 이름(실명 아님)
 │   "AI는 같은 이름이라도 일하는 방식이 달라요" │  ← 오늘 배운 한 줄(2줄 이내)
 │      [카드][카드][카드][카드]              │  ← 이 강 능력 카드 아이콘
 │ ────────────────────────────────────── │
 │   나도 루키 키우기  ▶  (초대 코드 자리)       │  ← 친구 부르는 줄
 └──────────────────────────────────────────┘
```
- 종류 3가지: **강 클리어 카드**(기본) / **승진 카드**(이전 모습 → 새 모습 나란히, "헤드셋으로 승진!") / **부 완주 카드**(그 부 카드 아이콘 전부).
- 개인정보: **실명·학교·점수는 기본으로 안 넣음.** 별(★)은 "별 보이기" 스위치를 켤 때만(기본 꺼짐). 루키 이름 + 닉네임만.
- 앱 안 미리 보기는 320px 폭. 버튼: [단톡방에 보내기](주) [이미지 저장](보조) [닫기].
- 실제 밖으로 내보내기(단톡방·SNS)는 "처음 밖에 공개하는 일"이라 출시 때 캡틴 결재 대상(지금 시제품은 모양만).
