# 연습 앱 v0.3 사용 설명서 (트랙 B)

> **한 줄 요약**: 서버·로그인 없이 휴대폰 브라우저에서 도는 **연습용 퀴즈 웹페이지**입니다. 연습 31문항만 들어 있고, 진단·평가 문항은 하나도 들어 있지 않습니다(자동 검사로 확인).

---

## 1. 내 컴퓨터에서 열어 보기 (1-2-3)

1. **터미널**(까만 글자 창)을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다.
   ```
   cd ~/wsuk/04_제품개발팀/app/public && python3 -m http.server 8000 --bind 127.0.0.1
   ```
   (`127.0.0.1`은 "이 컴퓨터 안에서만" 열린다는 뜻입니다. 인터넷에 공개되지 않습니다.)
2. 크롬 주소창에 **`http://127.0.0.1:8000`**을 넣습니다. 첫 화면이 뜨면 `TEST1` 같은 가짜 코드로 풀어 봅니다.
   - 휴대폰 화면처럼 보려면 크롬에서 F12 → 왼쪽 위 휴대폰 모양 아이콘을 누릅니다.
   - 교수님 지정 링크 시험: `http://127.0.0.1:8000/?ids=L11-Q1,L12-Q1,L12-Q2,L11-Q4,L13-Q5,L14-Q1`
3. 다 봤으면 터미널에서 **Ctrl + C**를 눌러 임시 서버를 끕니다.

> 더 간단하게: `public/index.html` 파일을 더블클릭해도 열립니다(이어 풀기 등 일부는 브라우저에 따라 다르게 동작할 수 있어 위 방법을 권장).
> 휴대폰 10대 시연 점검(같은 와이파이)은 `--bind 127.0.0.1`을 뺀 명령을 씁니다 — 이때도 같은 와이파이 안에서만 보이며, **인터넷 공개(Firebase Hosting)는 결재3 승인 후**입니다.

## 2. 문항을 고친 뒤 데이터 다시 만들기 (1-2-3)

1. 교육기획팀 원본 `03_교육기획팀/문항은행/questions_part1-3.json` 또는 `quiz_sets.json`을 고칩니다. (앱 폴더의 `public/data/practice.js`는 **직접 고치지 않습니다** — 자동으로 만들어지는 파일입니다.)
2. 터미널에서:
   ```
   cd ~/wsuk && python3 04_제품개발팀/app/tools/build_data.py
   ```
3. 결과를 읽습니다.
   - `[빌드 성공] 연습 31문항(P1 10 · P2 10 · P3 11), 세트 3개, 진단·평가 0개` → 끝. 브라우저를 새로고침하면 반영됩니다.
   - `[빌드 실패]` → 앱 파일은 **바뀌지 않습니다**. `✕` 줄에 이유가 적혀 있으니 원본을 고치고 다시 실행합니다.
   - `! 경고` → 앱은 만들어졌지만 확인할 것이 있다는 뜻입니다(예: 해설에 "2번" 같은 보기 위치 표현, 아직 draft인 문항 수).
   - 문항 수를 **일부러** 바꿨다면 `build_data.py` 안의 `EXPECTED` 숫자를 고쳐야 성공합니다(실수로 바뀐 것을 잡기 위한 장치).

## 3. 자동 테스트 다시 돌리기

```
cd ~/wsuk && node 04_제품개발팀/app/tests/run_tests.js          # 테스트 36개 중 자동 32개 (약 2분)
cd ~/wsuk && node 04_제품개발팀/app/tests/take_screenshots.js   # 390px 스크린샷 6장 다시 찍기
```
마지막 줄 `합계: 통과 32 · 실패 0`이면 정상입니다.

## 4. 폴더 설명

| 폴더/파일 | 무엇인가요 | 인터넷에 올리나요? |
|---|---|---|
| `public/` | **올릴 파일만** 모아 둔 곳 | ✅ 이 폴더만 올림 |
| `public/index.html` | 화면 뼈대 | ✅ |
| `public/style.css` | 꾸미기(색·글자 크기·밝게/어둡게) | ✅ |
| `public/app.js` | 동작(섞기·채점·이어 풀기·지정 링크) — 위에서 아래로 9칸으로 나눠 한국어 설명을 달아 둠 | ✅ |
| `public/data/practice.js` | 연습 31문항 + 연습 세트 3개 (자동 생성) | ✅ |
| `tools/build_data.py` | 원본에서 연습 문항만 골라 위 파일을 만드는 스크립트 + 안전 검사 | ❌ |
| `tests/` | 자동 테스트(`run_tests.js`), 스크린샷 촬영, 최근 결과(`results.json`) | ❌ |
| `screenshots/` | 390px 화면 사진 | ❌ |

## 5. 이 앱이 휴대폰에 남기는 것 (브라우저 안의 작은 메모장 = localStorage)

| 이름 | 내용 | 지워지는 때 |
|---|---|---|
| `levelup_practice_code` | 마지막에 넣은 참가자 코드 | 브라우저 기록 삭제 |
| `levelup_practice_run` | 풀던 판(문제·보기 순서, 고른 답) | 결과 화면 도착, [새로 시작] |
| `levelup_practice_theme` | 밝게/어둡게를 직접 고른 경우만 | 브라우저 기록 삭제 |

서버로 보내는 것은 없습니다. 처음 열 때 글꼴(Pretendard)을 인터넷에서 받아 오며, 받지 못하면 휴대폰 기본 글꼴로 보입니다.
