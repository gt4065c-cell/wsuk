## 1. 내 컴퓨터에서 열어 보기 (1-2-3)

1. 터미널(까만 글자 창)을 열고, **이 폴더(`04_제품개발팀/app`)**로 이동합니다.
   - 쉬운 방법: 터미널에 `cd `(cd 뒤에 빈칸 하나)까지 친 다음, 파일 탐색기(맥은 Finder)에서 `app` 폴더를 터미널 창으로 끌어다 놓고 Enter.
   - 그다음 아래 한 줄을 붙여 넣고 Enter:
   ```
   python3 -m http.server 8000 --bind 127.0.0.1 --directory public
   ```
   (`127.0.0.1` = "이 컴퓨터 안에서만" 열린다는 뜻. 인터넷에 공개되지 않습니다.)
2. 크롬 주소창에 **`http://127.0.0.1:8000`**을 넣습니다. 첫 화면이 뜨면 `TEST1` 같은 가짜 코드로 풀어 봅니다.
   - 휴대폰 화면처럼 보려면 크롬에서 F12 → 왼쪽 위 휴대폰 모양 아이콘.
   - 교수님 지정 링크 시험: `http://127.0.0.1:8000/?ids=L11-Q1,L12-Q1,L12-Q2,L11-Q4,L13-Q5,L14-Q1`
3. 다 봤으면 터미널에서 **Ctrl + C**를 눌러 임시 서버를 끕니다.

> `Address already in use`(이미 쓰는 번호)라고 나오면 `8000`을 `8001`처럼 다른 숫자로 바꾸고, 주소도 `:8001`로 바꿉니다.
> 더 간단하게: `public/index.html`을 더블클릭해도 열립니다(일부 브라우저는 이어 풀기가 다르게 동작할 수 있어 위 방법을 권장).

## 2. 휴대폰으로 시연 점검하기 (같은 와이파이 안에서만, 1~6단계)

> ⚠️ 이 방법은 **같은 와이파이에 연결된 기기에서만** 열립니다(인터넷 공개 아님). 그래도 같은 와이파이의 누구나 열 수 있으니 **시연이 끝나면 바로 Ctrl + C로 끄세요.** (인터넷 공개 주소는 따로 있습니다 → **7장** 참고. 캡틴 허락으로 Vercel에 임시 공개 중.)

1. **같은 와이파이 연결**: 노트북과 휴대폰을 같은 와이파이에 연결합니다. 학교 와이파이는 기기끼리 접속을 막는 경우가 있어(미확인), 안 열리면 휴대폰 1대의 **핫스팟**에 노트북과 다른 휴대폰을 모두 연결합니다.
2. **서버 켜기**: 이 폴더(`04_제품개발팀/app`)에서
   ```
   python3 -m http.server 8000 --bind 0.0.0.0 --directory public
   ```
   (`0.0.0.0` = 같은 와이파이의 다른 기기도 들어올 수 있게 연다는 뜻)
3. **방화벽 허용**: 처음 켤 때 "python이 네트워크 연결을 받도록 허용할까요?" 같은 창이 뜨면
   - 윈도우: **개인 네트워크만** 체크하고 [허용]. (공용 네트워크는 체크하지 않음)
   - 맥: [허용].
   - 창을 실수로 닫았으면 윈도우는 '설정 → Windows 보안 → 방화벽 → 방화벽에서 앱 허용', 맥은 '시스템 설정 → 네트워크 → 방화벽 → 옵션'에서 python을 허용합니다.
4. **노트북 주소(IP) 찾기**
   - 윈도우: 새 터미널에 `ipconfig` → "무선 LAN 어댑터 Wi-Fi" 아래 **IPv4 주소** (예: `192.168.0.12`)
   - 맥: 시스템 설정 → Wi-Fi → 연결된 와이파이 옆 [세부사항] → **IP 주소** (또는 터미널에 `ipconfig getifaddr en0`)
5. **휴대폰에서 열기**: 휴대폰 브라우저 주소창에 `http://192.168.0.12:8000`(내 IP로 바꾸기). 지정 링크는 `http://192.168.0.12:8000/?ids=L11-Q1,L12-Q1,...`
   - 안 열리면: ① 같은 와이파이인지 ② 방화벽 허용했는지 ③ 주소 앞이 `http://`인지(https 아님) ④ 핫스팟으로 바꿔 보기
   - 다른 번호를 쓰려면 명령의 `8000`과 주소의 `:8000`을 같이 바꿉니다.
6. **끝나면 바로 끄기**: 터미널에서 **Ctrl + C**.

## 3. 문항을 고친 뒤 데이터 다시 만들기 (1-2-3)

1. 교육기획팀 원본 `03_교육기획팀/문항은행/questions_part1-3.json` 또는 `quiz_sets.json`을 고칩니다. (앱의 `public/data/practice.js`는 **직접 고치지 않습니다** — 자동으로 만들어지는 파일입니다.)
2. 터미널에서 이 폴더(`04_제품개발팀/app`)로 이동해:
   ```
   python3 tools/build_data.py
   ```
3. 결과를 읽습니다.
   - `[빌드 성공] 연습 31문항(P1 10 · P2 10 · P3 11), 세트 3개, 진단·평가 0개` → 끝. 브라우저를 새로고침하면 반영됩니다.
   - `[빌드 실패]` → 앱 파일은 **바뀌지 않습니다**. `✕` 줄의 이유를 보고 원본을 고친 뒤 다시 실행합니다.
   - `! 경고` → 앱은 만들어졌지만 확인할 것이 있다는 뜻(예: 해설에 "2번" 같은 보기 위치 표현, 아직 draft인 문항 수).
   - 문항 수를 **일부러** 바꿨다면 `tools/build_data.py` 안의 `EXPECTED` 숫자를 고쳐야 성공합니다(실수로 바뀐 것을 잡기 위한 장치).

## 6. 이 앱이 휴대폰에 남기는 것 (브라우저 안의 작은 메모장 = localStorage)

| 이름 | 내용 | 지워지는 때 |
|---|---|---|
| `levelup_practice_code` | 마지막에 넣은 참가자 코드 | 브라우저 기록 삭제 |
| `levelup_practice_run` | 풀던 판(문제·보기 순서, 고른 답) | 결과 화면 도착, [새로 시작] |
| `levelup_practice_theme` | 밝게/어둡게를 직접 고른 경우만 | 브라우저 기록 삭제 |

- 서버로 보내는 것은 없습니다. 글꼴은 **휴대폰·컴퓨터의 기본 글꼴**을 써서, 처음 열 때도 바깥 서버에 요청하지 않습니다.

## 8. 알려진 제한

- **인터넷이 끊긴 상태에서 새로고침하면 앱이 열리지 않습니다.** (앱을 휴대폰에 따로 저장해 두지 않기 때문) 이미 열린 화면은 끊겨도 끝까지 풀 수 있으니, 와이파이·데이터가 끊기면 **새로고침하지 말고 그대로 계속 푸세요.** 다시 연결되어 주소를 열면 '이어 풀기'로 이어집니다.
- 같은 휴대폰에서 탭 두 개로 서로 다른 연습을 동시에 풀면, '이어 풀기' 기록은 마지막에 답한 탭 것만 남습니다.
- 휴대폰 '뒤로 가기'는 앱 안의 이전 화면으로 갑니다. 문제를 푸는 중에는 "그만 풀까요?"라고 묻고, 그만둬도 푼 기록은 남아 다시 열면 이어 풀 수 있습니다.
