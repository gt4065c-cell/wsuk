## 3. 우리에게 주는 시사점

### 차별화 3가지
1. **"우리 강의만 아는 튜터"** — 무료 AI(ChatGPT 공부 모드 등)는 범용(아무 과목이나). 우리 튜터는 **30강 대본 범위 안에서만** 힌트를 주고 "이건 12강에 나와요"처럼 강의로 돌려보냄. 범위가 좁아 비용도 적게 듦.
2. **"같은 기수 동료와 팀 실습"** — 조사한 성인 서비스들은 대부분 혼자 듣는 구조. 우리는 실제 한 반(동기)이 있으므로 **팀 퀘스트·서로 코드 봐주기**가 가능. 경쟁사가 가장 약한 부분.
3. **"힌트 3단계 + 횟수 제한"을 게임 규칙으로** — 1단계 질문 → 2단계 방향 힌트 → 3단계 예시. 힌트를 아껴 쓰면 보너스. 이렇게 하면 **월 1만 원 이하 사용량 제한**이 불편이 아니라 게임 재미가 됨. (비용 계산은 개발팀 확인 필요, 미확인)

### 하지 말아야 할 것
- **정답을 바로 주는 튜터** (콴다식) — 실습 과정의 목적(스스로 만들기)과 맞지 않음.
- **범용 챗봇 만들기** — 무료 ChatGPT·Gemini와 정면 경쟁이 되고 비용도 큼.
- **평가(공통 문항)에서 튜터 사용 허용** — 교훈노트 2026-11-01 "연습과 평가 분리" 규칙 위반. 튜터는 연습에서만.
- **성인에게 공개 꼴찌 순위** — 실무자는 체면을 중시할 수 있음 → 팀 순위·개인 성장 위주 권장 (근거 자료 미확인, 학습과학 연구원 확인 요청).
- 참고: 저장소가 공개 상태이므로 튜터용 정답·대본이 그대로 노출됨을 감안 (캡틴 결정 사항).
