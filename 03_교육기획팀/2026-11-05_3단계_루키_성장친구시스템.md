## 0. 핵심 재미 루프 (그림)

```
 ┌──────────────── 한 판 (강 1개, 6~10분) ────────────────┐
 │  루키가 업무를 망침 → 팀장이 원인을 찾아 가르침          │
 │       → 능력 카드 획득!(연출) → 다음 업무 …              │
 │       → 확인 문제 3개 → 30강 지도에 불 켜짐               │
 │       → 루키의 다음 강 예고 "내일은 제가 만든 게임이…"     │  ← "한 판만 더"
 └───────────────────────────┬──────────────────────────┘
                             ▼
 ┌──────────── 매일 (3~5분) ────────────┐   ┌────────── 친구와 ──────────┐
 │ 루키 아침 보고: "○○ 기술이 가물가물해요"│   │ 팀 사무실에 내 루키 출근     │
 │  → 기술 되살리기 3개 (복습 상자)        │──▶│ 친구 루키 방문·응원 스티커   │
 │  → 카드 별 +1, 출근 기록 이어짐          │   │ 함정 문의 도전장 주고받기    │
 │  → 오늘의 업무 의뢰 (수준 맞춤 연습)     │   │ 막히면 팀에 "도와줘요"       │
 └──────────────────────────────────────┘   └─────────────┬──────────────┘
                             ▼                              ▼
 ┌──────────── 매주 ────────────┐        ┌──────── 수업 시간 ────────┐
 │ 주간 업무 평가(공통 8문항)      │        │ 교수가 "보스전" 버튼       │
 │  → 팀 프로젝트 성공 도장(팀)    │        │ 반 전체가 고장 난 프로젝트 │
 │ 사내 매뉴얼 당번(해설)          │        │ 를 3분 동안 함께 고침      │
 │ 부 마지막 주 → 루키 승진 발령   │        │ → 교수 화면: 헷갈린 개념   │
 └──────────────────────────────┘        └────────────────────────────┘
```

**왜 다시 오나**: 루키가 "내가 가르친 만큼만" 자라고(애착), 날마다 루키가 먼저 말을 걸며(되살리기), 팀 사무실에 친구 루키가 출근해 있기 때문(함께).
**왜 배우나**: 모든 보상은 "직접 해 보기(업무)·떠올리기(되살리기·평가)·설명하기(매뉴얼·도와주기·함정 만들기)"에만 붙습니다.

## 1. 루키 성장

### 1-1. 무엇이 자라는가 — 이름과 실제 의미 (교훈노트 2026-11-02)

| 화면 이름 | 실제로 세는 것 | 늘리려는 학습 행동 | 쓰지 않는 뜻 |
|---|---|---|---|
| **경력 XP / 경력 Lv** | 팀장이 루키에게 가르친 **학습량**(끝까지 한 업무·문항·복습) | 끝까지 해 보기, 꾸준히 하기 | 실력·성적 아님. 화면에 "경력 = 함께 일한 양" 고정 표시 |
| **능력 카드** | 스테이지에서 **그 업무를 끝까지 해 본 개념** 1장 | 직접 해 보기 | "익혔다(숙달)"는 뜻 아님 → 숙달은 아래 '단단한 카드'로만 |
| **카드 별 ★(0~4)** | 그 개념의 복습 상자를 **혼자 맞혀 통과한 횟수** (1·3·7·14일) | 간격 두고 떠올리기 | 별 4 = **"단단한 카드(복습 완료)"** |
| **직급(맡은 일)** | 루키가 지금 **몇 부의 업무를 하는지 = 진도** | 30강 끝까지 가기 | 승진 = 다음 부 업무를 맡음. 실력 판정 아님 |
| **도구 가방 아이템** | 그 도구를 다루는 강을 **수료**함 | 강 끝까지 하기 | — |
| **숙달 도장** | 주간 업무 평가(공통 문항) 8개 중 7개 이상 | 공통 기준으로 확실히 익히기 | 본인만 봄. 연습 정답률로는 절대 안 줌 |

### 1-2. 경력 XP 규칙표

| 언제 | 누가 | 받는 것 | 늘리려는 학습 행동 | 결재2와 비교 |
|---|---|---|---|---|
| 스테이지 업무 1개를 끝까지 마침 (틀려도, 다시 해도 같음) | 본인 | **30 XP** + 능력 카드 1장 | 직접 해 보고 결과 확인 | (제안) 새로 생김. 강당 1회, 다시 하기는 0 |
| 스테이지 끝 확인 문제 1개 끝까지 (해설까지 봄) | 본인 | **10 XP** (맞든 틀리든) | 끝까지 풀고 해설 확인 | 결재2 "문항 완료 10" 그대로 |
| 오늘의 업무 의뢰(수준 맞춤 연습) 1개 끝까지 | 본인 | **10 XP** (힌트 써도 같음) | 내 수준에서 연습 | 그대로 |
| 기술 되살리기(복습) 1개 끝까지 | 본인 | **10 XP**, 혼자 맞히면 **+5** ("되살리기 성공") | 간격 복습 | 그대로 (이름만 바꿈) |
| 틀린 뒤 "루키에게 왜 틀렸는지 한 줄 설명" | 본인 | **+5 XP** | 오답 원인 말로 정리 | (제안) 2단계 초안에 있던 것 부활 |
| 강 끝 "내 업무에 써 보기" 노트 작성 (1강: 내 업무 3개 분류) | 본인 | **10 XP** | 배운 것을 내 일에 옮기기 | (제안) 새로 생김. 강당 1회 |
| 주간 업무 평가 응시 (점수와 무관) | 본인 | **20 XP** | 도움 없이 떠올리기 | (제안) 결재2엔 0 |
| 사내 매뉴얼(해설)이 교수 확인 후 공개 | 당번 | **20 XP** + 매뉴얼 도장 | 또래에게 설명하기 | (제안) 결재2엔 0 |
| 팀원 매뉴얼 읽고 확인 + 한 줄 보충 | 팀원 | **10 XP** | 설명을 따져 읽기 | (제안) |
| "도와줘요"에 답해 질문자가 "도움 됨" | 답한 사람 | **10 XP** (하루 2회까지) | 동료 돕기 | (제안) |
| 수업 중 보스전 참여 (문항 1개 이상 끝까지) | 본인 | **10 XP** + 보스전 기념 카드 | 수업 중 떠올리기·토론 | (제안) |
| 팀 프로젝트(주간 팀 퀘스트) 성공 | 팀 전원 | **20 XP** + 사무실 소품 1개 | 팀원 모두 꾸준히 하기 | (제안) |

**주지 않는 것**: 로그인만, 응원 스티커 보내기, 친구 방문, 같은 문항 반복(복습 날 밖), 빨리 풀기, 연속 정답 보너스, 무작위 보상, 결제.
**하루 상한**: 반복할 수 있는 연습·복습 XP만 하루 200 (그대로). 스테이지·평가·매뉴얼은 강·주당 1회라 상한 밖.

### 1-3. 경력 Lv 곡선 — "처음엔 빨리, 뒤로 갈수록 천천히"

| 구간 | 한 레벨에 필요한 XP | 누적 XP |
|---|---|---|
| Lv.1 → 10 | 40씩 | Lv.10 = 360 |
| Lv.10 → 30 | 150씩 | Lv.30 = 3,360 |
| Lv.30 → 50 (최대) | 400씩 | Lv.50 = 11,360 |

- 1강 스테이지(업무 5개 + 확인 3개 = 180 XP)만 해도 **Lv.1 → Lv.5**: 첫날에 레벨업을 네 번 봅니다.
- 뒤로 가면 레벨업이 드물어지지만 **매 업무마다 능력 카드, 매 강마다 지도 불·도구, 매 부마다 승진**이 있어 "받는 것"이 끊기지 않습니다.
- 5레벨마다 꾸밈 하나(색, 책상 소품, 말풍선 모양)가 열립니다. 전부 학습량으로만 열리고 돈으로 사는 길은 없습니다.

### 1-4. 30강 동안의 성장 곡선 (예상치 — 연습 하루 5문항 안팎 기준, 첫 기수 기록 보고 조정)

| 부 (강) | 루키가 맡는 일 (직급) | 겉모습 변화 | 도구 가방에 들어오는 것 (그 강에서 배운 것) | 카드(누적, 약) | 경력 Lv (스테이지만 / 연습까지) |
|---|---|---|---|---|---|
| 1부 (1~5) | **수습 루키** — 일 맡기는 법 배우기 | 회색 몸 → 사원증 | 사원증(1강) · 요청서 클립보드(3강: 목표·자료·제약·완료 기준) · 돋보기(4강: 검증) | 22 | Lv.13 / Lv.16 |
| 2부 (6~13) | **게임 제작 담당** — 퀴즈게임 만들기 | 파란 몸 + 헤드셋 | 미니 게임기(10강) · 버그 잡이 그물(11강) · 되돌리기 시계(12강: Git) · 배포 로켓(13강) | 55 | Lv.23 / Lv.31 |
| 3부 (14~21) | **기록·출입 관리 담당** — 기억 창고·출입증 | 남색 몸 + 열쇠 꾸러미 | 기억 창고 열쇠(15강) · 출입증(16강: UID) · 권한 열쇠고리(17강) · 실시간 안테나(20강) · 서버 채점 도장(21강) | 90 | Lv.31 / Lv.40 |
| 4부 (22~25) | **학습 튜터** — 학생 돕는 AI로 | 보라 몸 + 튜터 명찰 | 비밀 금고(22강: 키는 서버에) · 오답 설명 노트(23강) · 도구 벨트(24강) · 포털 문(25강) | 105 | Lv.32 / Lv.44 |
| 5부 (26~30) | **에이전트 팀장 루키** — 도구 가방 채우기 | 금색 몸 + 학사모(30강 수료) | 화면 확인 안경(26강) · 연결 플러그(27강: MCP) · 점검 스킬북(28강) · 표 서랍장(29강) · 출시 점검표(30강) | 125 | Lv.35 / Lv.50 |

- **승진 조건 = 그 부의 강을 모두 수료 + 그 부 마지막 주 업무 평가 응시**. 점수는 조건이 아닙니다(못 봐서 승진을 못 하는 사람이 없게). 승진하면 "발령장" 카드와 새 겉모습.
- 도구 가방 = 20칸. 칸을 누르면 그 강의 핵심 한 줄과 능력 카드로 이어집니다(= 개념 찾아보기 목차).
- **30강 수료 장면**: 루키가 학사모를 쓰고 "이제 제가 다음 기수 신입을 맞이할게요" — 완주의 끝을 이야기로 닫습니다.
- 꾸밈: 첫날 **이름 짓기 + 몸 색 1개 고르기**(애착). 그 뒤 꾸밈은 위의 학습량·진도로만 열림.

## 2. 매일 돌아오게 하는 장치

### 2-1. 기술 되살리기 (= 복습 상자 1·3·7·14일)

| 단계 | 화면 | 실제 규칙 |
|---|---|---|
| 아침 보고 | 루키: "팀장님, 어제 배운 **규칙 따르기**가 가물가물해요…" 카드가 반쯤 흐리게 | 복습 상자 날짜가 된 문항이 있음 (앱이 실제로 잊었는지 재는 게 아님 → 카드 아래 작은 글씨 "다시 꺼낼 때가 된 기술") |
| 되살리기 | 새 사례로 묻기: "이번엔 '휴학 하고 싶어요' 문의예요. 규칙표가 나눌까요?" | 같은 개념의 **다른 사례 문항** 우선(학습과학: 새 맥락으로 떠올리기). 없으면 원래 문항 |
| 성공 | 카드가 다시 선명해지고 별 +1, "기억났어요!" | 혼자 맞힘 → 다음 상자, +5 XP |
| 실패 | 루키: "같이 다시 볼래요?" → 해설 → 카드는 그대로 남음 | 상자 1로. **카드·레벨·별은 절대 빼앗지 않음** |
| 별 4 | "단단한 카드" 금테 | 상자 4 통과 = 복습 완료 |

늘리려는 행동: 간격 두고 떠올리기(인출 연습). 잃는 것이 없어서 "실패하기 싫어 안 하기"가 생기지 않게.

### 2-2. 출근 기록 (= 연속 학습일)

| 항목 | 규칙 (2단계 그대로, 이름만 루키 세계로) |
|---|---|
| 출근한 날 | 되살리기·업무 의뢰·스테이지 중 **3개 이상 끝까지** |
| 휴가 | **매주 2일**까지 안 와도 끊기지 않음(자동). 루키 책상에 "휴가 중" 팻말 |
| 야근 복구 | 휴가를 다 쓴 뒤 하루 놓치면, 다음 날 안에 되살리기 5개 → 이어짐 (주 1회) |
| 끊겼을 때 | 0으로 지우지 않고 "최장 출근 기록" 함께 표시. 루키는 아프거나 우울해지지 않음 ("다시 오셔서 반가워요!") |
| 표시 | `출근 15일째 (출근 12 · 휴가 3)` — 실제 출근과 휴가를 나눠 셈 |

### 2-3. 오늘의 업무 (하루 3~5분 묶음)
- 홈 첫 화면 = 루키가 말하는 **오늘 할 일 3칸**: ① 되살리기 n개 ② 업무 의뢰(수준 맞춤 연습) 3개 ③ (선택) 팀 사무실 들르기.
- 3칸을 채우면 루키가 퇴근 인사 + 다음 강 예고(호기심 고리). 칸을 다 못 채워도 벌 없음.
- 알림은 **하루 1번, 학습자가 고른 시각**에만. 문구는 루키 말투("팀장님, 오늘 두 개만 같이 봐요").

### 2-4. 다음 강 예고 (끝맺음 고리)
강이 끝날 때마다 루키가 다음 강의 "사고"를 예고: 예) 9강 끝 "내일 제가 만든 퀴즈게임, 점수가 이상하게 나온대요…" → 10강 시작 장면과 이어짐. 커리큘럼 설계자의 스테이지 첫 장면(문제 먼저)과 맞춤.

## 3. 친구 시스템

### 3-0. 진행 순서 (첫 회차 경쟁 없음 — 교훈노트 2026-11-01)

| 주차 | 열리는 것 |
|---|---|
| 1주차 | 혼자: 루키 이름 짓기, 스테이지, 되살리기. 친구 기능은 **방문·응원만**. 보스전은 "반 전체 협동"만 |
| 2주차~ | 팀 사무실, 팀 프로젝트, 사내 매뉴얼 당번, 도전장 |

### 3-1. 팀 루키 사무실 (3~4명, 2단계 지그재그 편성 그대로)

| 무엇 | 규칙 | 늘리려는 학습 행동 |
|---|---|---|
| 사무실 화면 | 팀원 루키들이 책상에 앉아 있음. 보이는 것: **별명, 루키 겉모습, 지금 몇 강, 오늘 출근했는지** | 서로 진도 맞추기 |
| 안 보이는 것 | 점수, 정답 수, 맞힌 비율, 경력 Lv 비교표, 등수 | — |
| 팀 프로젝트 (주간 팀 퀘스트) | 팀원 **각자 칸** 1개씩: 이번 주 업무 의뢰·되살리기 10개 끝까지. 모든 칸이 차면 성공 → 전원 20 XP + 사무실 소품(화분, 화이트보드…) | 모두가 꾸준히 연습 |
| 무임승차 방지 | 칸이 사람마다 따로라 한 사람이 대신 못 채움. 칸은 "채움/아직"만 보이고 숫자는 안 보임 | — |
| 바쁜 팀원 | "이번 주 휴가" 누르면 그 칸이 빠짐(사유 안 물음, 팀원에겐 "휴가"로만). 팀 끄기도 언제든 | — |
| 팀 프로젝트 성공 도장 | 주간 업무 평가(공통 8문항) 팀 평균 ≥ 15 → **"팀 프로젝트 성공(학습목표 달성)"** 도장 (2단계 판정 그대로). 반 전체엔 성공 팀만 | 팀원 모두가 배우도록 돕기 |

> 사무실 문구: `7팀 사무실 — 바다의 루키(8강) · 소나무의 루키(7강) · 하늘의 루키(8강, 오늘 출근 ✓). 이번 주 팀 프로젝트 3/4칸.`

### 3-2. 친구 루키 방문 + 응원
- 친구 루키 방에 가면 겉모습, 도구 가방, **본인이 공개로 고른** 능력 카드만 보임.
- 응원 스티커(커피, 박수, "같이 가요") 하루 친구당 1개. **XP 없음**(학습 행동이 아니므로). 받은 사람 루키가 기뻐하는 연출만.

### 3-3. 도움 요청 "도와줘요"
- 업무 의뢰에서 힌트 L2까지 봐도 막히면 → "팀에 물어보기" 버튼. 루키가 팀 메신저에 "우리 팀장님이 이 의뢰에서 헷갈려해요"를 올림(별명만, **연습 문항만**, 평가 문항은 버튼 없음).
- 팀원은 **정답 대신 생각 길잡이**로 답함(칸 안내: "어디를 보면 좋을까?"). 질문자가 "도움 됨"을 누르면 답한 사람 10 XP(하루 2회).
- 늘리려는 행동: 막혔을 때 묻기, 남에게 설명하기.

### 3-4. 도전장 — 1:1, 수준이 달라도 공정하게

| 종류 | 방법 | 공정한 이유 | 늘리려는 학습 행동 |
|---|---|---|---|
| **① 함정 문의 도전장** (주력) | 내가 강에서 배운 걸로 **루키를 헷갈리게 할 사례 1개**를 만들어 보냄 (예: 1강 "규칙표가 놓칠 문의를 써 봐"). 친구는 "분류·생성·도구 실행 중 뭘까 / 규칙표가 나눌까"를 판정하고 이유 한 줄 | 문제를 만든 사람과 푼 사람 모두 생각을 써야 함. 맞고 틀림보다 **서로의 이유를 나란히 보기**가 결과 화면 | 사례 만들기(생성), 판단 근거 말하기 |
| **② 같이 풀기 도전장** | 같은 개념의 문항 5개를 **각자 자기 수준(맞힐 확률 75~90%)으로** 받아 풂 | 둘 다 "4개쯤 맞힐" 문항이라 비교가 공정 | 같은 날 함께 연습 |
| 결과 화면 | 기본은 **"둘 다 완료! 둘이 합쳐 루키들이 의뢰 10건 처리"** + 각자 가장 헷갈린 문항 하나씩 공유 | 개인 점수는 서로 안 보임 | 헷갈린 것 함께 보기 |
| 점수 비교 | **두 사람이 모두 "보여 주기"를 켰을 때만** 나란히. 이긴 쪽은 스티커만, 추가 XP 없음 | 원치 않는 비교 없음 | — |

- 성장 마케터 제안 "민지 님이 4개 맞혔어요, 이길 수 있어요?"는 점수 노출이라 이렇게 바꿈: `민지 님의 루키가 도전장을 보냈어요 — "규칙표를 피해 가는 문의" 1건. 팀장님 판정은?`
- 도전장 XP = 그 안에서 끝까지 푼 문항 수 × 10(일반 연습과 같음, 하루 상한 안). 연습이므로 팀 판정·평가에는 안 들어감.

### 3-5. 수업 중 "팀 프로젝트 보스전" (교수가 여는 퀴즈 배틀)

| 단계 | 시간 | 누가 | 무엇을 |
|---|---|---|---|
| 열기 | 0초 | 교수 | 교수 화면 → 강 고르기 → [보스전 시작]. 학생 휴대폰·빔 화면에 **"고장 난 반 프로젝트"** 등장 (예: 10강이면 "점수가 안 매겨지는 퀴즈게임 몬스터") |
| 1막 부품 고치기 | 2분 | 팀마다 | 팀마다 고칠 부품 1개(화면·처리·저장 등)를 받음. 각자 **자기 수준 연습 문항**을 풀어 맞힐 때마다 부품 수리 게이지 ↑. 틀리면 해설 한 줄 보고 다음 문항 — **깎이는 것 없음**(아무도 팀을 망치지 않음) |
| 지원 출동 | 1막 중 | 먼저 끝난 팀 | 자기 부품을 다 고친 팀의 정답은 **아직 못 고친 팀의 부품**으로 들어감 → 빠른 팀이 느린 팀을 돕는 구조 |
| 2막 보스의 함정 | 약 2분 | 반 전체 | **모두 같은 문항 1개**(그 강의 대표 헷갈림) → 1차 투표 → 팀끼리 30초 이야기 → 2차 투표. 2차 정답 비율이 오른 만큼 큰 일격 (빔 화면엔 반 전체 %만) |
| 끝 | — | 교수 화면 | "가장 많이 헷갈린 개념 2개"와 2막 1차→2차 변화 → 교수가 바로 짚어 줌 |
| 보상 | — | 참여자 전원 | 10 XP + 보스전 기념 카드(반 전체 같은 카드) + 팀 사무실 트로피 |

- 게이지 크기는 **참여 인원에 맞춰 자동**(누가 결석해도 깰 수 있게).
- 빔 화면에 **개인 이름·팀별 순위·팀별 수리 속도는 보이지 않음**. 보이는 것: 몬스터 체력, 부품 불빛, 반 전체 %.
- 보스전 결과는 팀 판정·개인 기록 어디에도 안 들어감(연습).
- 늘리려는 행동: 수업 중 바로 떠올리기, 친구와 이유 따지기(동료 토론), 교수의 즉시 보충.

### 3-6. 공유 카드 (성장 마케터 제안 반영)

| 카드 | 언제 | 담는 것 | 담지 않는 것 |
|---|---|---|---|
| 오늘의 루키 카드 | 강 수료 | 루키 그림 · 별명 · "오늘 루키가 배운 한 줄" · 받은 능력 카드 아이콘 · 몇 강 수료 | 점수, 별(정답 수), 경력 Lv 비교 |
| 승진 발령장 | 부 수료 | 새 직급 · 새 겉모습 · 도구 가방 | 평가 점수 |
| "내가 만든 것" 카드 | 10강·13강·25강처럼 실제 결과물을 만드는 강 | 내 퀴즈게임·포털 화면 그림 (+ 본인이 원하면 링크) | 개인정보 |
| 보스전 기념 카드 | 보스전 끝 | 반 전체가 함께 깬 몬스터 | 개인 기여도 |

- 버튼: [단톡방에 보내기] [이미지 저장]. 실명 대신 별명. 링크 공개는 본인이 고름.
- 늘리려는 행동: **점수가 아니라 배운 것**을 남에게 말하기(설명하면 더 오래 남음).

## 4. 기존 기능을 루키 세계로 옮기는 표

| 기존 기능 (2단계) | 루키 세계 이름 | 화면에서 어떻게 보이나 | 그대로 지키는 규칙 |
|---|---|---|---|
| 진단 12문항 | **팀장 첫 출근 체크** | 루키가 "팀장님은 어디까지 아세요?" 12개를 물음. 결과는 상·중·하 없이 "팀장님께 맞는 의뢰로 준비할게요" | 맞춤·힌트·AI 꺼짐, 결과 등급 표시 없음 |
| 수준 맞춤 연습 (Elo, 맞힐 확률 75~90%) | **오늘의 업무 의뢰** | 학생·동료가 루키에게 보낸 의뢰서 모양 문항 | 난이도 이름 숨김, 힌트 써도 XP 같음 |
| 4단계 힌트 사다리 | **루키의 SOS 질문** | L1 루키가 되물음("'권한'은 뭘 정하는 거예요?") → L2 루키가 관련 능력 카드를 꺼내 보여 줌(강 번호) → L3 "이건 확실히 아니래요" 오답 하나 지움 → L4 선배 노트(정답+해설) | 10초 기다림, L3부터 **"루키에게 설명하기 한 줄"**(=내 생각 한 줄), L4는 답을 1번 낸 뒤 |
| AI 튜터 (월 1만 원 이하) | **선배 AI 멘토** | L4 뒤 "멘토 선배에게 물어보기". 멘토는 답을 주지 않고 되물어 줌 | 연습에서만, 하루 5회 = "오늘 상담 5회", 9,000원 넘으면 "멘토 선배가 이번 달 상담을 다 했어요. 선배 노트는 계속 볼 수 있어요" |
| 복습 상자 (1·3·7·14일) | **기술 되살리기** | 흐려진 능력 카드 → 새 사례로 묻기 → 선명해지며 별 +1 | 평가·진단 문항은 절대 안 들어감, 실패해도 잃는 것 없음 |
| 개념 정리 카드 | **능력 카드** | 업무 끝 연출로 받는 카드(3줄 요점) | 내용은 강의대본 근거만 |
| 경험치(XP) · 레벨 없음 | **경력 XP · 경력 Lv** | 상단 바 Lv + 루키 크기·표정 | "경력 = 함께 일한 양" 표시, 실력처럼 부르지 않음 |
| 배지 5개 | **도구 가방 · 단단한 카드 · 매뉴얼 도장 · 숙달 도장 · 출근 4주** | 루키 방 벽·가방에 걸림 | 이름 = 실제 일어난 일 |
| 연속 학습일 | **출근 기록** | 루키 책상 불, 휴가 팻말 | 주 2일 휴가, 야근 복구 1회, 최장 기록 보존 |
| 팀 (3~4명 지그재그) | **팀 루키 사무실** | 팀원 루키들이 책상에 앉아 있음 | 별명 가나다순, 수준 말 없음, 팀 끄기 가능 |
| 주간 팀 참여 목표 | **팀 프로젝트(주간)** | 사람마다 칸 1개, 다 차면 사무실 소품 | 칸은 채움/아직만, 휴가 칸 빼기 |
| 주간 공통 점검 8문항 | **주간 업무 평가 (평가관 방문)** | 평가관 루키가 옴. "평가 중엔 루키도 멘토도 쉬어요" — 힌트·AI·맞춤 꺼짐 | 1번만, 본인 화면엔 "응시 완료" + 다시 볼 기술만 |
| 부 마지막 주 공통 점검 | **승진 전 업무 평가 → 승진 발령** | 응시하면(점수 무관) 부 수료와 함께 승진 | 점수는 승진 조건 아님 |
| 학습목표 달성 (팀 평균 ≥ 15) | **팀 프로젝트 성공 도장** | 사무실 벽 도장, 반 전체엔 성공 팀만 | 판정은 공통 문항으로만 |
| 해설 당번 (주 1회) | **사내 매뉴얼 당번** | "신입 루키 교육 매뉴얼 한 장" 쓰기(정답의 이유 / 그럴듯한 오답이 틀린 이유 / 내 업무라면) → 팀원 확인 → 교수 승인 → **반 전체 매뉴얼 책장**에 꽂힘 | 순번 돌림, 1회 미루기, 연습 문항만, 반려는 당번에게만 |
| 질문 게시판 | **"도와줘요" 팀 메신저** | 루키가 대신 물어봄 | 연습 문항만, "도움 됨" 하루 2회 |
| 1단계 수업 퀴즈 대결 (Socrative) | **팀 프로젝트 보스전** | 교수 버튼 → 3~4분 협동 | 깎이는 것 없음, 개인 이름·팀 순위 안 보임 |
| 교수 화면 | **교수 상황판** | 강별 막힌 개념, 보스전 결과, 매뉴얼 승인함 | 개인 점수는 교수만 |

## 5. 학습자의 하루 시나리오 (3주차 화요일, 직장인 "하늘" 님, 오늘 저녁 수업 있음)

| 시각 | 하는 일 | 받는 것 |
|---|---|---|

## 8. 결정·협의가 필요한 것

1. **(결재2) 경험치 규칙 추가**: 스테이지 업무 30, 오답 한 줄 +5, 내 업무 노트 10, 주간 평가 응시 20, 매뉴얼 20, 도움 10, 보스전 10, 팀 프로젝트 20 — 비서실장 정리 후 결재2에 올림. 바꾸지 않는 것: 문항 완료 10, 복습 혼자 맞힘 +5, 하루 상한 200.
2. **부 경계** 5부(시제품) vs 커리큘럼 6부 — 커리큘럼 설계자의 이야기 지도에 맞춤.
3. **새 사례 되살리기 문항**: 개념마다 다른 사례 문항 1~2개 필요 — 커리큘럼 설계자 협의.
4. **보스전 실시간 연결**: 무료 범위 안에서 가능한지 — 서비스 기획자·앱 개발자 확인.
5. **도전장·함정 문의 글 검사**(부적절한 글 거르기) 방식 — 서비스 기획자.
