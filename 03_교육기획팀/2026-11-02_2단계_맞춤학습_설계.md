## ① Elo 수준 조절 (연습용)

### 숫자 정의
| 이름 | 뜻 | 시작값 |
|---|---|---|
| θ (세타) | 학습자 실력 | **0** (진단 전) |
| b | 문항 난이도 | 문항의 `difficulty` 값으로 매핑: **1 → −1 / 2 → 0 / 3 → +1** |
| c | 찍어서 맞힐 확률 | **1 ÷ 보기 수** (4지선다 0.25, OX 0.5) |
| n_learner | 학습자가 Elo에 반영된 답 수 | 0 |
| n_item | 문항이 받은 응답 수(학습자별 첫 응답만) | 0 |

### 공식
- 맞힐 확률: **P = c + (1 − c) × 1 / (1 + e^−(θ − b))**
- 결과값 R: 아래 표 ③의 결과 이름에 따라 1 / 0.5 / 0
- 학습자: **θ ← θ + K_learner × (R − P)**, K_learner = **0.8 / (1 + 0.05 × n_learner)**
- 문항: **n_item < 10 이면 b 고정**(교수 설정값 유지). n_item ≥ 10 이면 **b ← b − K_item × (R − P)**, K_item = 0.8 / (1 + 0.05 × n_item)
- 범위 제한: θ는 −3 ~ +3, b는 −2.5 ~ +2.5 안에서만 움직입니다.
- Elo는 **문항 하나당 한 번**, 문항이 "마감"될 때만 고칩니다. 복습으로 다시 푼 답은 Elo에 반영하지 않습니다(외워서 맞힌 효과 제외).

### 다음 문제 고르기 규칙표
| # | 만약 ~라면 | → 이렇게 한다 |
|---|---|---|
| E1 | 연습 시작 | 후보 = 교수가 열어 둔 강의의 `PRACTICE` 문항 − 최근 7일 안에 푼 문항 − 복습 상자에 있는 문항 |
| E2 | 후보 중 P가 **0.75~0.90**인 문항이 있음 | 그중 **아직 안 푼 문항 우선**, 같으면 무작위 1개 |
| E3 | 0.75~0.90 문항이 없음 | P가 **0.82에 가장 가까운** 문항 1개 |
| E4 | 바로 전 2문항이 연속 R = 0 | 다음 문항은 후보 중 **P가 가장 높은 문항** + 앞에 "개념 정리 카드"(해당 강 요약 3줄) 1장. 문구: "이 개념을 한 번 정리하고 갈게요" |
| E5 | 같은 강 문항이 연속 3개 | 4번째는 다른 강에서 고름(섞어 풀기) |
| E6 | 후보가 0개(다 풀었음) | 7일이 지난 "혼자 맞힘"·"복습 완료" 문항을 다시 후보로 |
| E7 | 화면 표시 | θ·b·P 숫자, "레벨", "상/중/하"는 **학습자 화면에 절대 표시 안 함** |

> 계산 확인: θ = 0이면 P 0.75~0.90 구간에는 쉬움(b=−1) 문항만 들어옵니다. θ ≈ 0.7부터 보통, θ ≈ 1.7부터 어려움 문항이 들어옵니다(4지선다 기준).

## ② 복습 상자 (1·3·7·14일)

| # | 만약 ~라면 | → 이렇게 한다 |
|---|---|---|
| R1 | 연습 문항 결과가 "혼자 맞힘"이 **아님** | 상자 1에 넣고, 다음 복습일 = 오늘 + 1일 |
| R2 | 복습에서 **혼자 맞힘** | 상자 +1. 다음 복습일 = 오늘 + (상자2: 3일 / 상자3: 7일 / 상자4: 14일) |
| R3 | 상자 4에서 혼자 맞힘 | "복습 완료" 처리, 상자에서 뺌 |
| R4 | 복습에서 혼자 맞힘이 아님(힌트 사용 포함) | **상자 1**로, 다음 복습일 = 오늘 + 1일. 문구: "한 번 더 만나요" (틀렸다는 표현 X) |
| R5 | 하루 복습 고르기 | 복습일이 오늘 이전인 문항 중 **오래 밀린 순으로 최대 5문항**. 같은 강은 하루 최대 2문항 |
| R6 | 6개 이상 밀림(주말·결석) | 쌓아 보여 주지 않음. 남은 것은 다음 날로(5개 한도 유지), "밀린 숙제" 숫자 표시 안 함 |
| R7 | 하루 순서 | **복습 먼저 → 새 연습 문제** |
| R8 | 복습 때 힌트 | 사용 가능(연습 모드). 다만 쓰면 R4 적용 |

## ③ 4단계 힌트 사다리 (연습에서만)

### 단계별로 열리는 조건
| 단계 | 내용 | 열리는 조건 |
|---|---|---|
| L1 되묻기 | "이 문제에서 '권한'은 무엇을 정하는 걸까요?" | 문항 화면에서 바로 |
| L2 방향 | 관련 개념 + 강 번호 | L1을 본 뒤 **10초** 경과 |
| L3 부분 풀이 | 오답 보기 하나가 왜 틀렸는지 | L2를 본 뒤 10초 + **"내 생각 한 줄"** 입력(1글자 이상, 내용 검사 X) |
| L4 정답 + 해설 | 정답과 해설 | L3를 본 뒤 10초 + 한 줄 입력 + **답을 1번 이상 제출한 뒤** |

- 한 번 누르면 **한 단계만** 열립니다. 건너뛰기 없음.
- 힌트는 **미리 만들고 교수가 검토한 글**을 보여 줍니다(AI 호출 없음, 비용 0원).

### 제출과 마감 규칙
| # | 만약 ~라면 | → 이렇게 한다 |
|---|---|---|
| H1 | 연습 문항 한 개 | 제출은 **최대 2번** |
| H2 | 1번째 제출이 오답 | 정답은 숨기고 "힌트 L1 보기"를 권함(강요 X). 2번째 제출 가능 |
| H3 | 2번째 제출도 오답 | 문항 마감, L4(정답+해설) 자동 공개 |
| H4 | 정답 제출 | 문항 마감, 해설 공개 |
| H5 | L4를 본 뒤 제출 | 기록은 남기되 결과는 "정답 보고 이해"로 고정 |

### 결과 이름 (이름 = 실제 의미, 교훈노트 2026-11-02)
| 결과 이름 | 조건 | Elo R | 복습 상자 |
|---|---|---|---|
| 혼자 맞힘 | 힌트 0개, 1번째 제출 정답 | 1 | 안 넣음 |
| 힌트로 해결 | L1~L3 중 하나 이상 보고 정답 | 0.5 | 상자 1 |
| 두 번째에 맞힘 | 힌트 0개, 1번째 오답 → 2번째 정답 | 0.5 | 상자 1 |
| 정답 보고 이해 | L4를 봄 또는 2번 모두 오답 | 0 | 상자 1 |

### 경험치(XP) 처리 — 벌점처럼 느껴지지 않게
| # | 만약 ~라면 | → 이렇게 한다 |
|---|---|---|
| X1 | 문항을 끝까지 마감(결과 무관) | +10 XP |
| X2 | 결과가 혼자 맞힘 / 힌트로 해결 / 두 번째에 맞힘 | +5 XP 추가 (**셋 다 같은 15 XP** — 힌트를 써도 XP가 줄지 않음) |
| X3 | 결과가 정답 보고 이해 | +10 XP만. 화면 문구: "이 문제는 복습 때 다시 만나요. 그때 혼자 맞히면 +10 XP" |
| X4 | 복습에서 혼자 맞힘 | +10 XP ("다시 도전 성공") |
| X5 | 공통 | XP는 **절대 빼지 않음**. "힌트 사용 횟수"는 학습자 본인 기록에만 표시, 친구·팀에게 안 보임 |
| X6 | XP 용도 | 꾸미기·연속 학습일 등 재미 요소에만. **향상점수·순위·성적에 쓰지 않음** (세부 보상은 게임화 기획자와 맞춤) |

## ⑤ 진단 (첫 접속)

| # | 만약 ~라면 | → 이렇게 한다 |
|---|---|---|
| D1 | 처음 접속 | `DIAG` **12문항**(1·2·3부 각 4, 난이도 1·2·3 각 4)을 **모두 같은 순서**로 냄. 진행 중 정오답 표시 X |

## 알려진 한계와 다음 할 일
1. **어려워하는 학습자에게 맞는 문항이 부족합니다.** 계산상 θ가 약 −0.3보다 낮으면 가장 쉬운 문항도 맞힐 확률이 75% 미만입니다. → 커리큘럼 설계자에게 **"아주 쉬운 확인 문항"(b = −2, 강마다 1개)** 추가를 요청할 것을 제안합니다.
2. K값 0.8, 목표 75~90%, 10초 대기, 하루 5회, 비용 차단 기준 9,000원은 모두 **출발값**입니다(연구로 정해진 최적값 없음). 첫 기수 기록을 보고 조정합니다.
3. "10초 대기 + 한 줄 쓰기"가 너무 번거로워 힌트를 아예 안 쓰는 학습자가 늘면(힌트 회피) 대기 시간을 줄입니다. 확인 지표: 문항 마감 결과 중 "정답 보고 이해" 비율과 힌트 사용률.
4. AI 튜터가 학습을 **늘린다고 약속하지 않습니다.** AI 튜터 사용자/미사용자의 공통 평가 점수를 비교해 확인합니다(데이터 분석가).
5. 교수 화면 지표(반 전체 많이 틀린 문항)는 이번 범위에서 "문항별 '정답 보고 이해' 비율 상위 5개"로 시작하고, 세부는 서비스 기획자 PRD에서 정합니다.
6. 이 문서에는 정답·평가 문항 내용이 없습니다. 미리 만든 힌트(L4 = 정답)는 저장소 공개 상태이므로 공개됩니다(캡틴 결정으로 감수 중).
