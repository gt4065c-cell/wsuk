# 08강 CSS와 JavaScript로 꾸미고 움직이기
> 읽는 시간: 약 5분

## 핵심 개념
같은 버튼이라도 색을 바꾸는 일과, 눌렀을 때 설명이 뜨게 하는 일은 역할이 달라요.

- HTML: 버튼과 설명 칸이 "있다"는 뼈대를 만들어요.
- CSS: 색, 크기, 여백 같은 생김새를 정해요.
- 자바스크립트: 클릭했을 때 무슨 일을 할지 정해요.

세 가지는 한 파일에 같이 들어갈 수도 있고, 파일을 나눌 수도 있어요. 처음에는 한 파일 안에서 세 위치를 찾아봐요. 한 파일에 있다고 하는 일까지 같은 건 아니에요. 고치려는 목적에 맞는 부분을 찾아야 해요.

## 예시
"정답 보기" 버튼을 손보는 장면이에요.

| 하고 싶은 일 | 고칠 곳 | 함께 볼 것 |
|---|---|---|
| 버튼 배경색 바꾸기 | CSS | 선택자(꾸밈을 받을 대상을 고르는 이름)를 보고 다른 글자 색까지 바뀌지 않게 하기, 글자와 배경의 대비 |
| 손가락으로 누르기 편하게 키우기 | CSS | 실제로 쓸 휴대폰 크기에서도 글이 겹치거나 삐져나오지 않는지 |
| 누르면 설명 보이기, 또 누르면 숨기기 | 자바스크립트 | 한 번만 눌러 보면 닫기 오류를 놓쳐요. 꼭 두 차례 눌러 보기 |

클릭을 알아채는 코드와 보여 줄 대상은 같은 이름으로 정확히 이어져 있어야 해요. 버튼 이름만 바꾸고 코드 속 이름은 그대로 두면 눌러도 아무 반응이 없을 수 있어요. 코드를 다 읽지 못해도 이 짝은 눈으로 맞춰 볼 수 있어요. 버튼 글자도 "설명 보기", "설명 숨기기"로 바뀌면 지금 상태를 알기 쉬워요.

## 꼭 기억할 3가지
- HTML은 뼈대, CSS는 색과 크기, 자바스크립트는 눌렀을 때 할 일이에요.
- 꾸미기가 끝났다고 기능까지 끝난 건 아니에요. 색을 바꾼 뒤엔 버튼이 제대로 눌리는지, 기능을 바꾼 뒤엔 글이 잘 보이는지 서로 챙겨요.
- 버튼 이름을 바꾸면 그 이름을 부르는 코드도 같이 맞춰야 해요.
