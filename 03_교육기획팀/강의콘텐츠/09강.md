# 09강 바이브코딩으로 요청하고 실행하고 수정하기
> 읽는 시간: 약 5분

## 핵심 개념
바이브코딩은 바라는 기능을 평소 쓰는 말(자연어)로 풀어 설명하면서 AI와 같이 만드는 방식을 널리 부르는 이름이에요. 코드는 AI가 고쳐도, 원하는 결과가 맞는지 확인하는 사람은 우리예요.

핵심은 느낌만 전하고 끝내지 않는 거예요. 누가 어느 화면에서 무엇을 하는지, 어느 부분을 바꾸면 되는지 정해서 말해요. 처음부터 큰 서비스를 한꺼번에 시키면 뭔가 잘못됐을 때 어디가 탈인지 알기 힘들어요. 그래서 잘 돌아가는 페이지에 기능을 하나씩 더해요.

## 예시
선택지 버튼을 휴대폰에서 누르기 편하게 바꾸는 장면이에요.

1. 준비: 잘 돌아가는 처음 파일과 지금 화면을 남겨 둬요. 바꿀 것은 버튼뿐이고, 정답과 점수 계산은 건드리지 말라고 적어요.
2. 부탁: 휴대폰 화면에서 선택지 글자가 잘리지 않고 버튼 사이 간격이 넉넉하게 해 달라고 해요.
3. 확인: AI가 고쳤다고 말해도 바뀐 파일이 무엇인지 찾아 직접 열어 봐요. 설명만 오고 파일은 그대로인 경우도 있어요.
4. 다시 부탁: 짧은 보기는 괜찮은데 긴 문장이 버튼 밖으로 삐져나왔어요. "다시 예쁘게"가 아니라, 어떤 화면 너비에서 어느 문장이 넘쳤는지 구체적으로 알려요.
5. 마무리: 긴 문장이 버튼 안에서 줄을 바꾸는지, 눌렀을 때 채점도 예전처럼 되는지 봐요. 원하는 결과가 나오면 거기서 멈춰요.

작은 성공을 기록하고 다음 기능으로 넘어가면, 탈이 나도 어느 수정부터 살펴볼지 알 수 있어요.

## 꼭 기억할 3가지
- 바이브코딩은 바라는 기능을 말로 풀어 AI와 같이 만드는 방식이에요.
- 부탁하고, 돌려 보고, 확인하고, 고치기를 여러 번 되풀이해요. 안 된 점은 구체적으로 돌려줘요.
- AI가 "다 됐어요"라고 해도 파일과 화면을 내 눈으로 확인해요.
