# 22강 서버를 거쳐 AI API 호출하기
> 읽는 시간: 약 5분

## 핵심 개념
AI API는 프로그램이 AI 모델의 기능을 불러 쓰는 통로입니다. 이 통로를 쓰려면 비밀 키(내 계정임을 증명하는 열쇠 문자열)가 필요해요. 이 키가 웹페이지 코드에 들어 있으면 누구나 개발자 도구(브라우저 속을 들여다보는 기능)로 꺼내 볼 수 있습니다.

그래서 흐름을 이렇게 나눕니다. 브라우저는 우리 서버에 질문과 문항 번호만 보내고, 서버가 비밀 키로 AI를 부른 뒤 답을 다시 화면으로 돌려줘요. 키는 끝까지 서버 안에만 있습니다.

서버는 AI를 부르기 전에 문지기 역할을 합니다. 로그인하지 않은 요청은 거절하고, 너무 긴 질문은 막고, 허용된 문항인지 확인해요. 누가 물었는지는 브라우저가 적어 보낸 이름 대신 서버가 확인한 로그인 정보로 판단합니다. 아무나 계속 부를 수 있게 두면 요금과 부담이 커지기 때문이에요. 참고로 AI 채팅 서비스 구독료와 API 사용 요금은 서로 별개로 생각해야 합니다.

## 예시
| 장면 | 화면이 보여 줄 것 |
|---|---|
| 질문을 보내고 기다리는 중 | 버튼에 "처리 중" 표시, 반복 클릭 잠시 막기 |
| 답이 도착함 | AI 답을 글자로만 표시 (웹페이지 코드로 끼워 넣지 않음) |
| 시간이 너무 오래 걸림 | "잠시 후 다시 시도해 주세요" 안내, 다시 시도는 몇 번까지만 |
| 로그인 안 한 요청 | 서버가 거절 |

실패했는데 빈 답을 성공처럼 보여 주면 학생은 무엇이 문제인지 모릅니다. 또 개발자 도구에서 키가 보였다면, 서버로 옮기는 것으로 끝내지 말고 이미 새어 나간 키를 새것으로 바꾸는 것도 검토해야 해요.

## 꼭 기억할 3가지
- AI 비밀 키는 서버에만 두고, 브라우저는 서버에게 질문만 보내요.
- 서버는 AI를 부르기 전에 로그인, 질문 길이, 허용 문항을 검사해요.
- AI 답은 글자로만 보여 주고, 실패하면 실패라고 솔직히 알려요.
