# 26강 Claude Code와 Chrome으로 화면 검증하기
> 읽는 시간: 약 5분

## 핵심 개념
AI가 "코드를 고쳤어요"라고 해도, 실제로 버튼을 눌러 보면 엉뚱한 화면으로 갈 때가 있습니다. 이번 강에서는 AI의 완료 보고에 진짜 화면 확인을 붙입니다.

역할이 다른 두 도구를 함께 써요. 하나는 프로젝트 파일 속 코드를 읽고 고치는 Claude이고, 다른 하나는 Claude in Chrome(크롬 브라우저 확장 프로그램)으로 웹 화면을 보며 대신 눌러 보고 페이지를 옮겨 다닙니다. 이름이 비슷한 다른 확장 프로그램과 헷갈리지 말고 공식 안내를 확인하세요.

브라우저 작업은 실제 사이트에 영향을 줄 수 있어요. 그래서 범위를 먼저 정합니다. 연습용 계정과 시험 화면만 열어 두고, 메시지 보내기나 계정 설정 바꾸기는 하지 말라고 미리 말해 둬요. 개인 업무 탭은 닫아 둡니다.

## 예시
포털의 홈 버튼을 점검한 장면입니다.

| 단계 | 한 일 |
|---|---|
| 1. 시험 | 퀴즈 카드로 들어가 첫 문항을 띄운 뒤 홈 버튼 누르기 |
| 2. 발견 | 퀴즈는 열리는데 홈 버튼이 엉뚱한 곳으로 감 |
| 3. 수정 | 코드 담당 AI에게 그 링크 한 군데만 고치게 하고, 바뀐 부분 확인 |
| 4. 재확인 | 고친 화면을 열고 처음과 똑같은 순서로 한 번 더 눌러 보기 |

AI가 "확인했어요"라고 해도 실제로 어느 주소로 갔는지 직접 봐요. 또 고친 코드와 지금 열린 화면이 같은 버전인지 맞춰야 헛짚지 않습니다. 자동 점검은 되풀이 확인에 편하지만, 학생들이 실제로 쓰는 여러 휴대폰까지 다 대신 봐 주지는 못해요.

## 꼭 기억할 3가지
- 코드 고치는 Claude와 화면을 눌러 보는 Claude in Chrome은 역할이 달라요.
- 브라우저 점검은 연습용 계정과 화면에서, 꼭 필요한 만큼만 누르게 해요.
- AI의 "봤어요"보다 실제로 이동한 주소와 결과를 믿어요.
