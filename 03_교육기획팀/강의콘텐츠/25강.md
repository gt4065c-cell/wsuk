# 25강 학습게임과 AI 도우미를 교육 포털로 모으기
> 읽는 시간: 약 5분

## 핵심 개념
퀴즈 주소, 용어카드 주소를 따로따로 보내면 학생은 어디로 가야 할지 헷갈립니다. 포털은 이런 학습 도구들로 들어가는 하나의 현관이에요. 학생이 무엇부터 할지 바로 알 수 있고, 어느 도구에 있든 홈으로 돌아올 수 있으면 됩니다.

주의할 점이 있어요. 링크를 한곳에 모았다고 로그인과 학습 기록까지 저절로 하나가 되지는 않습니다. 이번 실습은 세 도구를 같은 사이트 주소 안(/quiz, /cards, /tutor)에 두고 같은 Firebase 로그인을 쓰도록 미리 맞춰 두었어요. 그래도 각 화면이 지금 누가 로그인했는지 확인하고, 그 사람에게 허락된 자료만 불러오게 연결해야 합니다. 다른 사이트 주소의 서비스를 붙인다면 로그인 상태를 함께 쓰는 문제를 따로 살펴야 해요.

## 예시
포털 홈의 카드 세 장을 이렇게 씁니다.

| 카드 | 한 문장 설명 |
|---|---|
| 퀴즈 | 오늘 배운 내용을 확인해요 |
| 용어카드 | 핵심 표현을 복습해요 |
| AI 학습도우미 | 틀린 이유를 알아봐요 |

학생에게 궁금한 건 기술 이름이 아니라 "여기서 뭘 하지?"예요. 그러니 데이터베이스나 API 같은 말은 빼요. 카드마다 실제 주소를 연결하고 하나씩 눌러 봅니다. 예쁜 버튼이라도 주소가 비어 있으면 서비스가 아니에요. 아직 안 된 기능은 눌리는 척하지 말고 준비 중임을 솔직히 표시합니다. 휴대폰에서는 카드를 세로로 놓고, 제목이 잘리지 않는지도 확인해요.

## 꼭 기억할 3가지
- 포털은 퀴즈·용어카드·도우미로 들어가는 하나의 현관이에요.
- 링크를 모았다고 로그인과 기록까지 저절로 하나가 되진 않아요.
- 아직 안 된 기능은 눌리는 척 말고 준비 중임을 솔직히 표시해요.
