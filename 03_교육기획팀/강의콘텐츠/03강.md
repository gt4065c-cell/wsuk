# 03강 AI에게 일을 잘 맡기는 요청법
> 읽는 시간: 약 5분

## 핵심 개념
"퀴즈 만들어 줘"라고만 하면 AI는 학년도, 범위도 모른 채 마음대로 정해요. 같은 AI라도 무엇을 알려 주느냐에 따라 결과가 달라져요. 결과가 엉뚱하면 AI 실력만 탓하기 전에, 내가 빠뜨린 조건이 없었는지 먼저 살펴봐요. 특별한 주문을 외울 필요는 없어요. 일이 제대로 전해지는 요청문을 쓰면 돼요.

좋은 요청문에는 네 가지가 들어가요.

- 목표: 이 일로 무엇을 이루려는지
- 자료: 어떤 자료를 근거로 쓸지
- 제약: 지켜야 할 선, 하면 안 되는 일
- 완료 기준: 어떤 결과가 나오면 다 됐다고 볼지

요청문을 길게 쓰는 게 목적이 아니에요. AI가 모르는 빈 곳을 채워 주는 게 목적이에요. 조건끼리 부딪치지 않는지도 봐요. "아주 짧게, 하지만 모든 걸 자세히"처럼 맞지 않는 조건은 미리 고쳐 두세요.

## 예시
초급 학생용 확인 문제를 부탁하는 요청문이에요.

| 항목 | 요청문에 쓴 내용 |
|---|---|
| 목표 | 초급 학생이 세 용어를 구별하는지 확인 |
| 자료 | 아래 강의 메모만 사용 |
| 제약 | 메모 밖 사실이나 임상 판단은 넣지 않기 |
| 완료 기준 | 객관식 3문항, 정답, 짧은 해설, 원문 근거 |

자료를 붙일 때는 제목과 본문을 나누고, 어디까지가 지시인지도 분명히 해요. 긴 문서를 통째로 넣기보다 이번 결과에 필요한 부분만 골라요.

결과를 받아 보니 셋째 문항에만 근거 문장이 빠져 있었어요. 이럴 때는 전부 다시 만들게 하지 말고, 빠진 그 부분만 짚어서 다시 부탁해요. 그래야 멀쩡했던 부분까지 흔들리지 않아요.

## 꼭 기억할 3가지
- 요청문에는 목표와 자료, 제약, 완료 기준을 함께 적어요.
- 길이보다 AI가 모를 빈 곳을 채우는 게 중요해요.
- 요청문이 좋아도 내용이 맞는지는 따로 봐야 해요. 전문 내용은 근거를 직접 읽어 확인해요.
