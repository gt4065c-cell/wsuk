# 13강 게임을 배포하고 휴대폰으로 접속하기
> 읽는 시간: 약 5분

## 핵심 개념
내 컴퓨터에서만 열리던 게임을 휴대폰에서도 열 수 있게 해 봐요. 호스팅은 웹페이지 파일을 방문자에게 내주는 곳이고, 배포는 준비한 파일을 그곳에 올려 적용하는 일이에요. 지금까지 만든 HTML·CSS·자바스크립트 게임은 Firebase Hosting(파이어베이스의 웹 파일 제공 서비스)에 올릴 수 있어요.

다만 호스팅만으로 서버에서 비밀 키를 쓰는 기능이 생기지는 않아요. 오늘 올리는 건 로그인이 필요 없는 연습 게임이에요.

주소도 오해하기 쉬워요. 주소를 안다고 로그인 권한이 생기지 않고, 주소가 복잡하다고 남이 못 들어오는 것도 아니에요. 사용자 확인과 접근 권한은 뒤에서 따로 붙여요.

## 예시
| 단계 | 확인할 것 |
|---|---|
| 올리기 전 | 어느 프로젝트에 무엇을 올리는지 봐요. 올릴 폴더에는 학생이 볼 파일만 두고, 연구 자료나 비밀 설정 파일은 빼요 |
| 폴더 맞추기 | index.html이 있는 곳과 Hosting 설정의 공개 폴더가 같아야 해요. 어긋나면 엉뚱한 기본 화면이 뜨거나 올리면 안 될 파일이 공개될 수 있어요 |
| 올리기 | firebase deploy --only hosting 명령은 웹 파일만 올려요. DB 규칙이나 서버 기능은 같이 올라가지 않아요 |
| 올린 뒤 | 나온 주소를 새 창과 휴대폰에서 열어 세 문항을 끝까지 풀어 봐요 |

제목을 살짝 바꿔 다시 올렸는데 휴대폰에 옛 제목이 보이면, 올린 프로젝트가 맞는지, 파일이 제자리에 있는지, 예전 화면이 저장돼 남은 건지(캐시) 차례로 살펴요.

## 꼭 기억할 3가지
- 호스팅은 웹 파일을 손님에게 내주는 곳, 배포는 그곳에 파일을 올리는 일이에요.
- 올릴 폴더에는 학생이 볼 파일만 넣고, 비밀 설정은 빼요.
- '배포 완료'가 떠도 다른 기기에서 새 화면이 보이는지 꼭 열어 봐요.

## 다음 단계
학생 전체에게 주소를 알리기 전에, 내 휴대폰으로 첫 문제부터 결과까지 먼저 점검해요. 다음 14강에서는 새로고침해도 남는 기록과 여러 기기가 함께 보는 기록을 구분해요. 이 강 연습 문제로 확인해 봐요.
