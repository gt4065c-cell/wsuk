# 2단계 앱 팀·게임 시스템 설계 (다음 기수, 성인 실무자)

## 한 줄 요약
**경험치(XP)는 '푼 문항·복습·해설'처럼 학습 행동에만 주고 힌트를 써도 깎지 않습니다. 첫 주는 혼자 시작하고, 2주차부터 진단 기반 혼합 3~4인 팀이 매주 공통 점검으로 '학습목표 달성'에 도전하며, 주 1회 해설 당번이 팀이 가장 많이 틀린 문항 해설을 씁니다(교수 확인 후 공개). 개인 등수·개인 점수는 누구에게도 공개하지 않고, 팀 순위는 달성한 팀만 보여 줍니다.**

- 작성: 교육기획팀 게임화 기획자 / 2026-11-02
- 근거: 2단계 결재1 승인본(`00_캡틴/결재함/2026-11-02_2단계_결재1_방향확정.md`), `02_리서치팀/2026-11-02_2단계_학습과학_AI튜터.md`(원칙 1·4·5), `02_리서치팀/2026-11-02_2단계_AI튜터_맞춤학습_시장조사.md`, 1단계 운영설계(`03_교육기획팀/2026-11-01_팀챌린지_운영설계.md`), 교훈노트
- 1단계에서 **그대로 재사용**: 개인 점수 0/10/20(보완 필요/유지/숙달 또는 향상, 4-2절), 기준점수 고정·결석 시 첫 응시 기준+보류(4-1, 3-2), 팀 점수 = 평균·15점 이상 "학습목표 달성"(4-7), 지그재그 팀 편성(3-1), 비경쟁 선택(4-9), 인정 문구 방식(4-8)
- 상태: 결재2 전 초안. **주간 공통 점검(8문항)의 문항 구성은 커리큘럼·맞춤학습 설계자와 맞춰야 함(협의 필요)**

## 0. 핵심 재미 루프

```
 [매일, 혼자]                                   [매주, 팀]
 내 수준 문제(맞힐 확률 75~90%)                   팀이 많이 틀린 문항 1개
   → 풀기 → (막히면) 4단계 힌트                    → 해설 당번이 해설 작성
   → 해설 확인 → 복습 상자(1·3·7·14일)             → 팀원 확인·한 줄 보충
        │                                          → 교수 확인 → 반 전체 공개
        ▼                                                  │
  XP + 연속 학습일 (나만 봄)                                 ▼
        │                            주간 공통 점검 8문항(혼자, 힌트·AI 꺼짐)
        └──────────────▶  개인 0/10/20(비공개) → 팀 평균 ≥ 15 → "학습목표 달성"
                                                   → 달성 팀만 순위 표시
```

**연결 고리**: 매일 혼자 하는 연습(수준별)은 XP·복습으로 보상하고, 팀의 성과는 **공통 점검(모두 같은 문항)** 으로만 판정합니다(교훈노트 2026-11-01). 연습 정답률은 팀 점수에 들어가지 않습니다.

## 1. 성장 시스템 (개인, 본인만 봄)

### 1-1. 경험치(XP) 규칙표

| 언제 | 누가 | 받는 것 | 늘리려는 학습 행동 |
|---|---|---|---|
| 연습 문항 1개를 끝까지 풀고 해설 화면까지 봄 | 본인 | **10 XP** — 혼자 맞힘·힌트로 해결·정답 보고 이해 **모두 같음** | 끝까지 풀고 해설로 확인하기 |
| 틀린 뒤 해설을 보고 "왜 틀렸는지" 한 줄 쓰기 | 본인 | +5 XP | 오답 원인 말로 정리(교정 피드백) |
| 복습 문항 1개 풀기 (맞든 틀리든) | 본인 | 10 XP | 간격 복습 |
| 복습 상자 4 통과 ("복습 완료") | 본인 | +10 XP | 장기 기억 굳히기 |
| 주간 공통 점검 응시 (점수와 무관) | 본인 | 20 XP | 혼자 떠올리기(인출 연습) |
| 해설 당번 해설이 교수 확인 후 공개됨 | 당번 | 30 XP | 또래에게 설명하기 |
| 팀원 해설 읽고 확인 + 한 줄 보충/질문 | 팀원 | 10 XP | 설명을 비판적으로 읽기 |
| 질문 게시판에서 내 답이 질문자에게 "도움 됨" 받음 | 답한 사람 | 10 XP (하루 2회까지) | 동료 돕기 |

**힌트가 벌점이 되지 않게**
- XP는 힌트 사용 여부와 **상관없이 같습니다.** 힌트를 써서 끝까지 푼 것도 학습 행동입니다(도움 회피 방지, 학습과학 보고서 주의 4).
- 힌트 남용은 XP가 아니라 **힌트 장치 자체**로 막습니다: 다음 단계는 10초 뒤, L2부터 "내 생각 한 줄", 정답(L4)은 답을 1번 낸 뒤(학습과학 원칙 1).
- 기록 이름은 그대로 셋으로 나눕니다: "혼자 맞힘 / 힌트로 해결 / 정답 보고 이해". 다만 이 구분은 **본인 기록과 난이도 조절에만** 쓰고 XP·팀 점수에는 쓰지 않습니다.

**XP를 주지 않는 것**: 로그인만 하기, 같은 문항 반복 풀기(복습 일정 밖), 빨리 풀기, 연속 정답 보너스, 무작위 보상, 결제.
**하루 상한**: 연습·복습 XP는 하루 200 XP(약 20문항)까지. 몰아서 하기보다 나눠 하기를 권하려는 것입니다.

**레벨은 두지 않습니다.** XP는 "얼마나 공부했나(학습량)"이지 실력이 아니므로, 실력처럼 보이는 레벨 이름을 붙이지 않습니다(교훈노트 2026-11-02). 대신 진도를 보여 줍니다.
> 화면 문구: `이번 주 학습량 320 XP · 푼 문항 24 · 복습 완료 3`

### 1-2. 연속 학습일

| 항목 | 규칙 |
|---|---|
| "학습한 날" 기준 | 그날 연습 또는 복습 **3문항 이상 끝까지 풀기** (해설까지 봄) |
| 쉬는 날 보호 | **매주 2일까지** 학습하지 않아도 끊기지 않음(자동). 직장인 야근·주말 고려 |
| 놓친 날 회복 | 보호일을 다 쓴 뒤 하루를 놓쳤다면, **다음 날 안에 복습 5문항**을 풀면 이어짐 (주 1회) |
| 끊겼을 때 | 0으로 지우지 않고 "최장 기록"을 함께 보여 줌 |
| 이름 | 실제 의미대로 표시: 학습한 날과 보호된 날을 나눠 셈 |

> 화면 문구: `연속 학습 15일째 (학습 12일 · 휴식 보호 3일)`
> 회복 안내: `어제는 학습 기록이 없습니다. 오늘 복습 5문항을 풀면 연속 기록이 이어집니다.`
> 끊긴 경우: `연속 기록이 새로 시작됩니다. 최장 기록 21일은 그대로 남아 있습니다.`

늘리려는 행동: 짧게라도 자주 공부하기(간격 효과). 놓쳐도 회복 장치가 있어 "어차피 끊겼다"는 포기를 막습니다.

### 1-3. 배지 5개 (이름 = 실제로 일어난 일)

| 배지 이름 | 받는 조건 | 늘리려는 학습 행동 |
|---|---|---|
| `[복습 완료 10]` | 문항 10개를 1·3·7·14일 복습까지 모두 혼자 맞힘 | 간격 복습을 끝까지 하기 |
| `[힌트로 해결 10]` | 힌트(L1~L3)를 쓰고 정답 보기 전에 스스로 맞힌 문항 10개 | 막혔을 때 포기하지 않고 힌트로 생각 이어가기 |
| `[○~○강 숙달]` | 해당 강의 범위 공통 점검에서 8문항 중 7개 이상 | 공통 기준으로 개념 확실히 익히기 (연습 정답률로는 주지 않음) |
| `[해설 공개]` | 내가 쓴 해설이 교수 확인을 거쳐 반 전체에 공개됨 | 동료에게 설명하기 |
| `[4주 연속 학습]` | 연속 학습일이 28일 이상 (보호일 포함, 배지 설명에 명시) | 꾸준히 학습하기 |

- "향상" 배지는 두지 않습니다. 8문항 점검으로는 개인 향상을 확실히 말하기 어렵기 때문입니다(1단계 4-12 해석 한계).
- 배지는 그림 캐릭터 없이 **글자 표시**. 본인 프로필에만 보이고, 원하면 팀에 공개 선택.

## 2. 함께하기 시스템 (팀)

### 2-1. 진행 순서
| 주차 | 내용 |
|---|---|
| 1주차 | **경쟁 없음.** 혼자 연습 + 진단(팀 편성용) + 기준 점검 8문항(기준점수, 고정) |
| 2주차~ | 팀 시작. 매주 연습 → 해설 당번 → 주간 공통 점검 → 결과 |

### 2-2. 팀 편성

| 항목 | 규칙 |
|---|---|
| 대상 | 같은 기수, 팀 기능을 켠 사람 |
| 인원 | 참여 인원 ÷ 4 올림 = 팀 수 → 모든 팀 3~4명 |
| 방법 | 1단계 3-1 지그재그 그대로: 진단 + 기준 점검 합산 정답률로 줄 세우기 → 지그재그 배분 → 팀 평균이 반 평균에서 10%p 넘게 벗어나면 맞바꾸기 |
| 겉모습 | 팀 이름은 무작위(예: "7팀"), 팀원 목록은 별명 가나다순. **상·중·하, 초급, 레벨 같은 말은 어디에도 없음** |
| 유지 | 기수 끝까지 같은 팀. 활동 인원이 1명이 되면 다른 팀에 합류 |
| 팀 끄기 | 언제든 끌 수 있음(비경쟁). 개인 학습·XP는 그대로. 팀원에게는 "팀 활동 쉼"으로만 보임 |

> 화면 문구(팀 발표): `이번 기수 팀이 정해졌습니다. 7팀 — 바다, 소나무, 하늘 (별명 가나다순). 팀은 여러 배경이 고르게 섞이도록 짰습니다.`

### 2-3. 주간 팀 목표

| 항목 | 규칙 | 늘리려는 학습 행동 |
|---|---|---|
| 주간 공통 점검 | 매주 같은 8문항(4지선다), **혼자, 힌트·AI 튜터 꺼짐**, 응시 기간 중 1번만 | 도움 없이 떠올리기 |
| 개인 점수 | 1단계 4-2 그대로: 7/8 이상 20 "숙달 또는 향상" / 기준+20%p 이상 20 / ±20%p 안 10 "유지" / 그 아래 0 "보완 필요"(교수만 봄). 기준점수 = 1주차 기준 점검(고정) | 처음의 나보다 나아지기, 확실히 익히기 |
| 팀 판정 | 응시한 팀원 평균 ≥ 15 → **"학습목표 달성"**, 미만 → **"도전 중"** | 팀원 모두가 배우도록 돕기 |
| 함께 보상 | 달성 팀 전원 +30 XP, 팀 기록에 `[학습목표 달성 ○주차]` | 협력 |
| 미응시 | 그 주 개인 점수 "기록 없음", 응시한 팀원만으로 평균(불이익 없음) | — |

> 화면 문구(달성): `7팀 — 이번 주 학습목표 달성. 팀원 다수가 개념을 확실히 익혔거나 처음보다 분명히 나아졌습니다.`
> 화면 문구(도전 중, 그 팀에게만): `이번 주는 도전 중입니다. 다음 주 기준도 각자의 1주차 결과라서 이번 결과는 넘어가지 않습니다.`

### 2-4. 주 1회 해설 당번

| 단계 | 언제 | 누가 | 무엇을 |
|---|---|---|---|
| ① 문항 선정 | 월요일 | 앱 자동 | 지난주 **팀 연습에서** 팀원이 가장 많이 틀린 문항 1개 (공통 점검 문항은 쓰지 않음 — 평가 문항 보호) |
| ② 작성 | 월~목 | 당번 1명 (돌아가며) | 템플릿 3칸, 합계 400자 이내: **정답의 이유 / 그럴듯한 오답이 틀린 이유 / 내 업무라면?** |
| ③ 팀 확인 | 목~금 | 나머지 팀원 | "확인" + 한 줄 보충 또는 질문 (각 10 XP) |
| ④ 교수 확인 | 금~일 | 교수 | 승인 → 반 전체 공개 / 수정 요청 → 당번에게만 의견 전달 |
| ⑤ 보상 | 공개 시 | 당번 30 XP + `[해설 공개]`, 팀원 확인자 각 10 XP | 또래 설명 |

**무임승차 대책**
- 당번은 앱이 순서를 정해 돌림 → 기수 동안 모두 같은 횟수.
- 팀원 몫(확인 + 한 줄)을 따로 두어, 당번 혼자만 하는 일이 되지 않게 함. 확인하지 않은 팀원은 확인 XP가 없을 뿐 벌점 없음.
- 팀 판정(학습목표 달성)에는 해설을 넣지 않음 → 해설 때문에 팀이 실패하는 압박이 없음.

**부담 대책**
- 400자 이내, 칸이 나뉜 템플릿. 강의 번호·관련 개념은 앱이 미리 채워 줌.
- **당번 미루기**: 기수 중 1회, 다음 순번과 바꾸기 가능(사유 묻지 않음).
- AI 튜터로 초안을 써도 되지만 "AI 도움 받음" 표시가 붙음. 교수 확인을 거치므로 오류는 공개 전에 걸러짐.
- 교수 수정 요청은 **당번에게만** 보이고, 반려 내용은 공개되지 않음.

> 화면 문구(당번 알림): `이번 주 7팀 해설 당번입니다. 팀에서 가장 많이 헷갈린 문항 1개 — "권한 범위" 관련(12강). 목요일까지 400자 이내로 작성해 주세요. 바쁜 주라면 한 번은 순번을 바꿀 수 있습니다.`
> 화면 문구(팀원): `바다 님의 해설이 올라왔습니다. 읽고 '확인'을 누르거나 보충할 점을 한 줄 남겨 주세요.`
> 화면 문구(공개): `7팀 해설이 교수 확인을 거쳐 공개되었습니다. — 12강 권한 범위`

### 2-5. 공개 범위와 순위

| 정보 | 본인 | 팀원 | 반 전체 | 교수 |
|---|---|---|---|---|
| XP·연속 학습일·배지 | O | 배지만 본인이 선택 시 | X | 합계만 |
| 개인 공통 점검 점수(0/10/20) | **X** (본인에게도 점수 대신 "응시 완료") | X | X | O |
| 개인 등수 | 없음 | 없음 | 없음 | 없음 |
| 팀 판정 | O | O | 달성 팀만 | O |
| 팀 순위 | — | — | **달성 팀만**, 같은 점수는 같은 순위, 팀원 수 표시 안 함 | O |
| 공개된 해설 | O | O | O | O |

> 화면 문구(반 전체): `3주차 학습목표 달성 팀: 2팀 · 5팀 · 7팀 · 9팀. 이번 주 반 전체 정답률이 가장 오른 개념은 '컨텍스트 관리'입니다.`

## 5. 부작용과 대책

| 부작용 | 대책 |
|---|---|
| 힌트를 쓰면 손해라 생각해 막혀도 안 씀 | XP 동일, 힌트 기록은 본인만 봄 |
| 힌트 연타로 정답만 보기 | XP가 아니라 힌트 장치(10초·한 줄·답 낸 뒤 정답)로 막음 |
| XP 쌓으려 쉬운 것만 반복 | 문항은 앱이 수준(75~90%)에 맞춰 배정, 복습 일정 밖 반복은 XP 없음, 하루 상한 |
| 하위권 팀원이 팀에 미안함 | 개인 점수 비공개, 점수는 '처음의 나' 기준, 도전 중 팀은 공개하지 않음 |
| 팀에 안 맞거나 바쁨 | 언제든 팀 끄기, 당번 순번 바꾸기 1회 |
| 연습 정답률을 팀 점수로 오해 | 팀 판정은 공통 점검만, 화면에 "팀 결과는 주간 공통 점검으로만 계산" 고정 표시 |
| 공통 점검 문항 유출 | 해설 당번은 연습 문항만, 공통 점검 해설은 응시 기간이 끝난 뒤 교수 화면으로만 |
| 8문항 점검의 우연성 | "참여 촉진 지표"로만 해석(교훈노트 2026-11-02), 1단계 4-12 한계 그대로 |
| 연속 기록 압박 | 주 2일 보호 + 회복 1회 + 최장 기록 보존 |
| 저장소 공개(public)로 해설·정답 노출 | 공개 해설은 원래 공개용. **공통 점검 문항은 공개 저장소에 두면 안 됨** → 개발 전 비서실장 확인 필요(사칙 7장) |

## 6. 결정·협의가 필요한 것
1. 개인 공통 점검 점수를 **본인에게도** 숨길지(초안) / 본인에게만 보일지 — 캡틴 결정
2. 주간 공통 점검 문항 수(30강 ÷ 약 8주 기준 주당 8문항 = 약 64문항 추가 필요) — 커리큘럼 설계자 협의
3. 공통 점검 문항 보관 장소(저장소가 공개 상태) — 비서실장 확인
