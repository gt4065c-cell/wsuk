# 미션 점검 — 학습과학 연구원 (2026-11-05)

> **한 줄 요약**: 지금 앱은 "글 읽고 → 글 퀴즈"라서 재미도 효과도 약하다. 1강은 "문제 먼저 → 그림으로 직접 해 보기 → 바로 반응 → 며칠 뒤 다시 꺼내기"로 바꿔야 한다.

## 1. 미션을 내 말로 + 내 기여
학생마다 자기 수준에서, 친구와 게임하듯 즐겁게 배우고 **실제로 실력이 남는** 앱. 나는 "재밌어 보이는 것"이 "배움에도 효과 있는지" 연구로 확인하고, 효과 없는 재미(점수만 쌓기)를 걸러 낸다.

## 2. 지금 효과가 약한 이유
1. **수동 학습**: 5분 글 읽기가 먼저다. 직접 해 보는 수업이 듣기만 하는 수업보다 성적이 높다(Freeman 2014).
2. **글만 있음**: 그림·도식이 없다. 그림+말이 말만보다 잘 남는다(Mayer).
3. **문제가 '글 기억하기'**: "01강에서 소개한 것은?"에 보기가 HTML·Git이라 생각 없이 맞힌다. 쉬운 인출은 효과가 작다(Roediger 2006).
4. **피드백이 늦고 글뿐**: '답 내기 → 해설 글'뿐, 무엇이 왜 틀렸는지 장면으로 안 보인다(Hattie 2007).
5. **동기 설계가 XP 숫자**: 완료 보상만 있고 호기심·이야기가 없다. 보상만 주면 흥미가 줄 수 있다(Deci 1999). 게임화 효과는 작고 엇갈린다(Sailer 2020).

## 3. 내가 놓친 점
그동안 연구원을 거의 부르지 않았는데도 먼저 나서지 않았다. "학습자가 재밌어하는가"를 시험하는 기준을 만든 적이 없다.

## 4. 1강 바꾸는 원칙 3개 (장면)
1. **문제 먼저, 설명 나중**(Kapur 2008): 첫 화면에 "학사 문의 10개를 규칙표로 나눠 보세요" 미니게임. 규칙이 "과목 바꾸고 싶어요"를 놓치는 순간 → "그래서 머신러닝이 나왔다" 설명.
2. **그림+짧은 말**: 1956년→규칙→머신러닝→딥러닝→생성형 AI를 넘기는 타임라인 카드 4장, 카드마다 한 문장.
3. **바로 반응 + 간격 두고 다시 꺼내기**(Cepeda 2006): 틀리면 "규칙표가 놓친 문의"가 빨갛게 튀어나옴. 이틀 뒤 친구 대결에서 "이 일은 분류·생성·도구 중 뭘까?" 새 사례로 다시 출제.
