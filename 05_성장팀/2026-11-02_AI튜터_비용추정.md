# 💰 AI 튜터 비용 추정 (2단계)

> 한 줄 요약: 가장 저렴한 최신 모델(Claude Haiku 5.5)로 힌트를 주면 **수강생 50명 기준 월 약 2천~5천 원**으로, 캡틴 예산(월 1만 원)에 들어갑니다. 더 똑똑한 모델은 예산을 넘습니다.

## 가격 (Anthropic 공식 API 요금, 2026-10 기준 자료, 100만 토큰당)
| 모델 | 입력 | 출력 | 특징 |
|---|---|---|---|
| **Claude Haiku 5.5** | $0.10 | $0.50 | 가장 저렴, 짧은 힌트에 충분 |
| Claude Sonnet 5.5 | $2.00 | $10.00 | 더 똑똑함, 약 20배 비쌈 |
| Claude Opus 5.5 | $4.00 | $20.00 | 가장 똑똑함, 약 40배 비쌈 |

> 토큰 = AI가 글을 세는 단위(한국어 1글자 ≈ 1~2토큰).

## 계산 가정
- 힌트 1번 = 입력 약 1,500토큰(문제·보기·해설·안내문) + 출력 약 200토큰(짧은 힌트)
- 수강생 50명 × 한 주에 30번 × 4주 = **월 6,000번**

| 모델 | 1번당 | 월 6,000번 | 원화(1$≈1,400원) |
|---|---|---|---|
| **Haiku 5.5** | 약 $0.00025 | 약 **$1.5** | **약 2,100원** |
| Sonnet 5.5 | 약 $0.005 | 약 $30 | 약 42,000원 ❌ 예산 초과 |

사용이 2배 많아도 Haiku 5.5는 약 4~5천 원입니다.

## 꼭 필요한 것 (결재 때 정할 것)
1. **Anthropic API 계정 + 결제 수단 등록** — 캡틴 명의, 돈이 드는 일이라 캡틴 승인 필요 (사칙 7장)
2. **월 사용 한도 설정** — 관리 화면에서 월 상한을 정해 두면 예산을 넘지 않음
3. **작은 서버 기능** — API 비밀키를 휴대폰 화면 코드에 넣으면 누구나 훔쳐 쓸 수 있어서, 키는 서버(예: Vercel 서버 함수)에만 둬야 함 → 지금의 '서버 없는 앱'에서 한 단계 늘어남
4. **1인당 횟수 제한** — 예: 한 문제에 힌트 3번, 하루 30번

## 참고
- 가격은 Anthropic 공식 요금표 기준이며 바뀔 수 있습니다(미래 변동 미확인).
- 실제 사용량은 2027년 1학기 첫 2주 기록으로 다시 계산합니다.
