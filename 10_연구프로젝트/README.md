| 직원 | 하는 일 |
|---|---|

| `gpt-strategy-director` 전략기획실장 (기존) | 연구주제·설계에 대한 반대 의견(심사위원 관점) |

## 진행 순서 — 결재 3번
```
[캡틴: 주제] → ① 문헌조사 → 사실검증(참고문헌 전수) → ② 동향·갭 분석 + 연구주제 후보
            → 🔴결재1 (연구주제 선택)
            → ③ 연구설계·목차 → GPT 심사위원 관점 검토 → 🔴결재2 (설계 확정)
            → ④ 연구 드래프트 → 참고문헌 재검증 → 품질검수 → 🔴결재3 (초안 완료)
```

## 폴더 규칙
주제마다 `10_연구프로젝트/YYYY-MM-DD_주제이름/` 폴더:
`00_주제접수.md` → `01_문헌목록.md` → `02_연구동향_연구주제후보.md` → `03_연구드래프트.md` (+ `사실검증.md`)
