캡틴의 피드백입니다: $ARGUMENTS

무한 피드백 루프를 실행하세요.

1. 피드백이 어떤 직원의 어떤 결과물에 대한 것인지 파악합니다. 화면 캡처가 있으면 무엇이 문제인지 먼저 쉬운 말로 확인합니다.
2. 해당 직원에게 결과물 수정을 맡깁니다 (오류라면 `app-developer` 수정 → `qa-tester` 재확인).
3. `01_비서실/교훈노트.md`에 한 줄을 추가합니다: 날짜 / 누구의 일 / 피드백 / 앞으로의 규칙 / 지시서 반영.
4. 같은 종류의 피드백이 전에도 있었거나 앞으로도 지켜야 할 규칙이라면, 해당 직원의 지시서(`.claude/agents/이름.md`)나 `CLAUDE.md`를 직접 고쳐 **영구 반영**합니다. 무엇을 고쳤는지 캡틴에게 알려 줍니다.
