# 자문 요청: "AI 루키 키우기" 게임형 학습 앱 설계에 대한 반대 의견

칭찬보다 반대 의견을 먼저, 표와 짧은 문장으로 답해 주세요. 불확실하면 "확실하지 않음"으로 표시해 주세요.

## 배경
- 대학 교수가 AI 에이전트들로 만드는 학습 웹앱. 대상: 'AI Agent 실무 과정'(30강) 성인 실무자·대학생 20~50명, 성적 미반영, 휴대폰 중심.
- 이전 버전(문제은행 + 요약 글)은 교수가 "재미없는 텍스트 사이트"라고 평가해 방향을 바꿈. 1강 시제품 3안 중 "루키 키우기"를 교수가 선택.

## 설계 요약
- 학습자 = 팀장, 신입 AI 에이전트 '루키'를 가르쳐 30강 동안 정식 에이전트로 키움. 5부(수습→사원→주임→튜터→파트너).
- 한 강 5~8분: 도입 대화 → 업무 2~5개(루키의 실수 잡기가 핵심) → 평가 3문제(1개는 새 사례) → 능력 카드·레벨(수료한 강 수)·30강 지도.
- 조작 부품 10종(분류 끌기, 짝, 순서, 틀린 곳 찾기, 고르기, 빈칸, 대화 선택, 카드 넘기기, 건네기, 미니 만들기) + 강별 내용 JSON 30개.
- 점수·성장은 첫 선택만 반영, 틀려도 3단계 도움. 복습 1·3·7·14일("기술 되살리기").
- 친구: 팀(3~4명) 루키 사무실 구경·응원·도전장, 수업 중 3분 협동 보스전. 개인 등수·점수 비공개.
- 기존 기능 재사용: 수준 맞춤 문항(Elo), 4단계 힌트, AI 튜터(하루 5회, 월 9,000원 상한), 주간 공통 점검.
- 일정: 11/9~1/31 30강 완성(약 13주: 엔진 3주 + 주 2~3강), 2월 시험.
- 근거: learning-by-teaching 메타분석 g≈0.35~0.56(대부분 초·중학생 대상).

3. 루키가 미리 정한 대본대로만 움직이면 "가르치며 배우기" 효과가 약하다는 지적이 있습니다. 적은 개발 비용으로 "내가 가르친 대로 루키가 달라지게" 만드는 방법은?
