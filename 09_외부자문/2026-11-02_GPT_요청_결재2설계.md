# 자문 요청: 팀 챌린지 설계(2차) 교차검토

칭찬보다 허점을 먼저 말해 주세요. 지난번 귀하의 지적을 반영해 고친 설계입니다.

## 1. 배경
- 코딩 초보 대학 교수가 AI 코딩 에이전트로 앱을 만듭니다(꿈: 수준별 학습을 친구와 게임처럼 하는 모바일 앱).
- 첫 적용: AI Agent 실무 과정 한 반 20~50명(성인 교수자·실무자). 성적 미반영, 예산 0원, 실명 없음.
- 1차 지적: ① 수준별 난이도와 향상점수 충돌 ② 진단 3~5문항 부족 ③ 기능 과다 ④ 성인의 체면 부담 ⑤ 점수 조작·중복 접속. 권고: 기존 도구+스프레드시트로 수업, 웹앱은 분리해 작게.

## 2. 바뀐 설계
**트랙 A (실제 수업, Socrative 무료 + 엑셀, 3회차)**
- 진단 12 / 공통 평가 A·B·C 각 8(난이도 맞춘 쌍둥이) / 연습 31, 겹침 없음. 수준별 출제는 연기.
- 1회차: 진단 → 평가A(팀 없음). 2·3회차: 3~4인 혼합 팀 연습 → 평가B·C.
- 수준 이름·개인 점수는 팀원에게도 비공개. 속도 가산점 없음. 순위는 활동 후 달성 팀만. 비경쟁 참여 선택 가능.

**점수 규칙** (위에서부터 처음 맞는 것 하나)
① 이번 7/8 이상 → 20점 ② 기준 +2문제 이상 → 20점 ③ ±1문제 → 10점 ④ −2문제 이상 → 0점(교수만 봄)
- 기준 = 평가A, 고정. 진단이 25%p 이상 높으면 둘의 평균. 1회차 결석자는 반 평균.
- 팀 점수 = 팀원 평균. 10점 이상 '성장 목표 달성', 15점 이상 '성장 우수'.

**트랙 B (웹앱, 수업과 분리)**: 코드 입장, 공통 퀴즈, 채점+해설, CSV 4개만.
- Firebase 무료(Realtime DB + 익명 로그인), Cloud Functions 없음.
- 휴대폰엔 정답 없는 문제지만. 답은 자기 자리 빈 칸에만 1회, 진행 중 회차만. 정답지는 연습은 답한 문항만 즉시, 진단·평가는 회차 종료 후에만 읽기 허용. 점수는 교수 화면이 서버 데이터로 재계산. 한 코드 = 한 기기.
- 제약: 같은 와이파이에서 새 계정 1시간 100개, 동시 연결 100개.
- 일정: 제작 11/5~13, 테스트 40개 11/14~18, 휴대폰 10대 모의 수업 11/19~22. 누락·중복 0, 채점 100% 일치여야 시연.
- 각자 속도로 풂. 정답·해설은 연습만 즉시, 진단·평가는 반 전체가 끝난 뒤. 참가자 코드는 4자리 종이 카드 한 장을 수업(Socrative)과 웹앱에서 공용. 웹앱 시연은 점수에 쓰지 않는 연습 세트로만(웹앱 서버에는 연습 문항만 저장, 진단·평가는 올리지 않음).

## 3. 질문
1. 1차 지적 ①~⑤를 각각 해결/부분/미해결로 판정하고 이유 한 줄.
2. 점수 규칙의 허점·악용 가능성은? (평가A 일부러 낮추기, 찍기 운, 천장·바닥 효과, 결석·비경쟁의 영향, 전원 '유지'면 달성인 10점 기준)
3. 보안 규칙 + 교수 화면 재채점으로 조작·정답 유출을 막을 수 있습니까? 구멍(익명 계정 여러 개, 코드 대입, 답한 뒤 정답지 열기, 휴대폰 쪽에서만 하는 제한 등)과 Functions 없이 메울 방법은?
4. 3주·테스트 40개가 코딩 초보+AI 에이전트에 현실적입니까? 줄인다면 무엇을?
5. 먼저 끝난 사람의 평가 답 유출에 "평가는 전원 종료 후 해설"이 충분합니까? 자기 답을 알려 주는 건 못 막는데 보완책은?
